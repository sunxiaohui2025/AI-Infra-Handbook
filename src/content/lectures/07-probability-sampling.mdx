上一讲用 softmax 把模型的打分变成了概率：TinyLM 读到“我”之后，下一个词是“我”的概率 0.4666，“爱”0.2076，“学”0.0613，AI 0.0764，“推理”0.0571，`<eos>` 0.131。

接下来要真的选出一个词，接在句子后面，再去生成下一个（第 24 讲）。最省事的办法是每次都挑概率最大的那个，可这样每次问同一个问题永远得到一模一样的回答，而且模型很容易陷入死循环反复说同一句话。大模型通常**按概率随机抽**：概率 0.47 的词，大约一半的时候被选中；概率 0.06 的词，偶尔也有机会被选中。

问题来了：计算机底层只会生成“0 到 1 之间完全均匀的随机数”，它怎么做到“按指定概率去抽”？抽很多次之后，结果又会怎样？这一讲把概率分布、采样算法和衡量分布不确定性的“熵”讲清楚。

## 概率分布

一个**概率分布**说的是：一件事有哪几种可能的结果，每种结果的可能性有多大。对“下一个词”来说，可能的结果就是词表里的每一个词，可能性就是 softmax 给出的概率。它必须满足两个条件：每个概率都在 0 到 1 之间；所有概率加起来正好等于 1。

结果只有有限个（或可数个）、每个都有一个明确概率的分布叫**离散分布**，大模型输出的就是离散分布。另一类是**连续分布**，比如“0 到 1 之间的任意实数，取到某一段的可能性恰好等于这一段的长度”，叫 **[0, 1) 上的均匀分布**。下面马上会看到，只要有了均匀分布，就能从任何离散分布里抽样。

## 怎么按概率抽：切尺子法

计算机能直接提供的随机数，是 [0, 1) 上均匀分布的随机数 u（比如 Python 的 `random.random()`），它落在 0 到 1 之间任何一个位置的可能性都完全相等。

怎么用一把均匀的随机数，按指定的概率去抽词？想象你有一根 1 米长的尺子，把它按每个词的概率依次切成 6 段，谁的概率大、谁占的线段就长；然后闭着眼睛往尺子上随机扎一针 u，扎到哪一段就选哪个词：

1. **算累积概率**：把概率从头开始依次加起来。“我”占 [0, 0.4666)，“我+爱”到 0.6742，再加“学”到 0.7355，再加 AI 到 0.8119，再加“推理”到 0.869，全部加完正好到 1。
2. **把 [0, 1) 切成 6 段**：[0, 0.4666) 归“我”，[0.4666, 0.6742) 归“爱”，[0.6742, 0.7355) 归“学”……每一段的长度恰好等于那个词的概率。
3. **抽一个 u，看它落在哪一段**：u = 0.3 落在第一段，选“我”；u = 0.7 落在第三段，选“学”；u = 0.95 落在最后一段，选 `<eos>`。

因为 u 在 [0, 1) 上是均匀乱扎的，它落进某一段的概率正好等于这段的长度，也就是那个词的概率。这个巧妙而简单的办法（数学上叫逆变换采样），就是所有采样器的底层原理。

## 抽多了，频率就接近概率

单独抽一次，结果是随机的。可抽很多次之后，每个词被选中的**频率**（实际出现的次数 ÷ 总次数）会越来越接近它原本的**概率**。这叫**大数定律**。代码用固定的随机种子抽了三组：

- **抽 10 次**：“我”的频率 0.3，“爱”0.3，AI 一次都没抽到（频率 0），和概率差得很远。
- **抽 100 次**：“我”0.42，“爱”0.19，大致接近了。
- **抽 10000 次**：“我”0.468，“爱”0.206，“学”0.064……和真实概率只差千分之几。

这提醒我们两件事：一是用模型生成一次回答，看到的只是一次抽样的偶然结果，不能代表模型的全部能力；二是评测模型（尤其是数学、代码能力）时，常常要对同一个问题生成多次、统计通过率（第 49、51 讲）。

## 随机种子

计算机里的“随机数”其实是用一个确定的数学公式算出来的一串数，只是看起来没有规律，叫**伪随机数**。公式的起点叫**随机种子**（seed）。种子相同，算出来的随机数序列就完全相同，抽样结果也就一模一样。

代码里的 `np.random.default_rng(0)` 就固定了种子 0，所以每次运行，抽 10 次的结果都是同样的那一组。调试、复现实验时，固定种子非常有用；在线推理服务里，一般每个请求用不同的种子，有的 API 允许用户自己指定 `seed`，以便复现同一个回答。

## 贪心和采样

**贪心解码**（greedy decoding）：每次都直接选概率最大的词，这里永远是“我”。结果确定、稳定，但容易单调、车轱辘话来回说。

**采样**（sampling）：按概率随机抽。结果丰富多样，但也可能不小心抽到概率很低、完全不通顺的冷门词。

两者之间有很多折中的办法：先用温度（第 6 讲）把分布变尖或变平，或者先把概率太低的词砍掉、只在概率最大的几个词里抽（Top-k、Top-p）。这些是第 73 讲解码策略的内容。

## 分布有多“不确定”：熵

有的分布很确定（一个词占了 99%，几乎没有悬念），有的分布很分散（6 个词概率都差不多，完全猜不到下一个是啥）。怎么用一个数衡量这种“不确定程度”？信息论里用的是**熵**（entropy）：

$$
H = -\sum_i p_i \ln p_i
$$

这个式子怎么来的？第 16 讲会讲到，−ln p<sub>i</sub> 可以理解成“看到结果 i 时有多吃惊”（概率越小越吃惊）；把每种结果的吃惊程度按它出现的概率 p<sub>i</sub> 加权平均，就是“平均有多吃惊”，也就是熵。

只有一个词可能（p = 1，其余为 0）时，1 × ln 1 = 0，熵为 0（毫无悬念）；n 个词完全均匀（每个概率 1/n）时，熵最大，等于 ln n。这里 6 个词的分布，熵是 **1.479**，最大可能是 ln 6 = 1.792，说明它比较分散、模型对下一个词并不笃定。熵和第 16 讲的交叉熵损失、困惑度紧密相关。

## 用代码复现

下面的代码读取 TinyLM 读到“我”之后的分布，算出累积概率，演示几个 u 落在哪一段；然后用固定的种子各抽 10、100、10000 次，统计频率；最后看贪心的结果和分布的熵。

```python
import json
import numpy as np

ex = json.load(open("tinylm.json", encoding="utf-8"))["examples"]["16"]
vocab, p = ex["vocab"], np.array(ex["p"][0])            # 第 6 讲算出的概率：读到“我”之后，下一个词的分布
print("分布：", dict(zip(vocab, p.tolist())), "，和 =", round(p.sum(), 4))

cdf = np.cumsum(p)                                       # 累积概率：把 [0, 1) 切成 6 段，每段的长度就是概率
print("累积：", np.round(cdf, 4).tolist())

def sample(u):                                           # 抽一个 [0, 1) 里均匀的随机数 u，看它落在哪一段
    return vocab[int(np.searchsorted(cdf, u, side="right"))]
for u in [0.3, 0.7, 0.95]:
    print(f"  u = {u} → {sample(u)}")

rng = np.random.default_rng(0)                           # 固定随机种子：每次运行抽到的结果都一样
for n in [10, 100, 10000]:
    draws = [sample(u) for u in rng.random(n)]
    freq = [draws.count(w) / n for w in vocab]
    print(f"抽 {n:5d} 次的频率：", np.round(freq, 3).tolist())

print("贪心（总取概率最大的）：", vocab[int(p.argmax())])
H = -(p * np.log(p)).sum()
print(f"熵 = {H:.3f}（6 个词均匀分布时最大，ln 6 = {np.log(6):.3f}；只有一个词时为 0）")
```

输出：

```text
分布： {'我': 0.4666, '爱': 0.2076, '学': 0.0613, 'AI': 0.0764, '推理': 0.0571, '<eos>': 0.131} ，和 = 1.0
累积： [0.4666, 0.6742, 0.7355, 0.8119, 0.869, 1.0]
  u = 0.3 → 我
  u = 0.7 → 学
  u = 0.95 → <eos>
抽    10 次的频率： [0.3, 0.3, 0.1, 0.0, 0.1, 0.2]
抽   100 次的频率： [0.42, 0.19, 0.08, 0.05, 0.06, 0.2]
抽 10000 次的频率： [0.468, 0.206, 0.064, 0.074, 0.062, 0.127]
贪心（总取概率最大的）： 我
熵 = 1.479（6 个词均匀分布时最大，ln 6 = 1.792；只有一个词时为 0）
```

第一、二行是分布和累积概率；接下来三行是 u = 0.3、0.7、0.95 各选中哪个词；然后是三组抽样的频率，次数越多越接近概率；最后是贪心的结果和熵。

## 容易混淆的地方

1. **概率高不等于一定被选中。**“我”的概率 0.47，意思是大约一半的时候被选中，另一半的时候选的是别的词。
2. **频率不等于概率。**频率是抽样的统计结果，会随抽样次数波动；概率是分布本身的性质。只有抽样次数足够多时，两者才接近。
3. **“随机”是可以复现的。**固定随机种子，同样的程序会得到同样的“随机”结果；换了种子或者换了运行环境（比如不同的 GPU 并行顺序），结果才会变。

## 回顾

概率分布描述一件事有哪些可能的结果、每种结果的可能性有多大，模型输出的下一个词的概率就是一个离散分布。按概率抽样的方法是：算累积概率，把 [0, 1) 切成长度等于各个概率的几段，抽一个均匀随机数 u，落在哪段选哪个。TinyLM 读到“我”后，u = 0.3 选“我”，u = 0.7 选“学”。抽得越多，频率越接近概率：抽 10 次差得很远，抽 10000 次“我”的频率是 0.468。随机种子决定了伪随机数序列，固定它就能复现结果。贪心总选概率最大的，采样按概率抽；熵衡量分布有多分散，这个分布的熵是 1.479。
