上一讲的残差连接让梯度能穿过很多层，但也留下了一个问题：每一层都往残差流里“加”东西，数值越叠越大。下面的代码里，一个 30 层的残差网络，第 1 层输出的向量长度是 3.4，第 10 层是 42.9，第 20 层是 2006.4，第 30 层到了 82441.6。数值这样失控，后面的层很难工作：激活函数会饱和，softmax 会一边倒，训练也会极不稳定。

这一讲的 **LayerNorm**（层归一化）就是来管这件事的。它在每一层的固定位置，把每个词的向量“拉回”统一的尺度：均值为 0、方差为 1。加上它之后，同一个网络每一层输出的长度都稳定在 4.0。

## 拉回到均值 0、方差 1

LayerNorm 对**每个词的向量**单独操作。设这个向量是 **x** = (x<sub>1</sub>, …, x<sub>d</sub>)，一共 d 个数：

1. 算这 d 个数的**均值** *μ*。
2. 每个数减去 *μ*，新的均值就是 0。
3. 算这 d 个数的**方差** *σ*²（每个数减去均值后平方，再取平均），开根号得到标准差。
4. 每个数除以标准差，新的方差就是 1。

写成一个式子：

$$
\mathrm{LN}(\mathbf{x}) = \frac{\mathbf{x} - \mu}{\sqrt{\sigma^2 + \epsilon}}
$$

分母里的 *ε* 是一个很小的数（比如 10<sup>−5</sup>），防止方差恰好为 0 时除以 0。

拿 TinyLM 算一下。第 1 层里，“AI”做完残差相加后的向量是 (−0.3872, −0.8882, 0.2983, 0.8035)。

- 均值：(−0.3872 − 0.8882 + 0.2983 + 0.8035) / 4 = −0.0434。
- 减去均值：(−0.3438, −0.8448, 0.3417, 0.8469)。
- 方差：这 4 个数平方的平均，0.4165；标准差 √(0.4165 + 0.00001) ≈ 0.6454。
- 除以标准差：(−0.5327, −1.3091, 0.5295, 1.3123)。

新向量的均值是 0、方差是 1。原来的形状（哪个数大、哪个数小、大多少）都保留了下来，只是整体的位置和尺度被统一了。因为方差是 1，d 个数平方的和就是 d，所以 LayerNorm 之后的向量长度总是 √d 左右：TinyLM 里是 √4 = 2，上面那个 16 维的网络里是 √16 = 4。不管前面的层把数值推到多大，这一步之后都回到同一个尺度。

## 缩放和平移：γ 和 β

强制每个向量都是均值 0、方差 1，有时候会限制网络：也许某一维本来就该整体偏大一点。所以 LayerNorm 最后还有一步：乘一个向量 *γ*、加一个向量 *β*：

$$
\mathrm{LN}(\mathbf{x}) = \gamma \odot \frac{\mathbf{x} - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta
$$

⊙ 表示逐元素相乘。*γ* 和 *β* 都是 d 维的、可以训练的参数，初始值分别是全 1 和全 0，也就是一开始什么都不改。训练中，网络可以通过它们给每一维单独调整尺度和偏移。TinyLM 没有训练，所以直接用 *γ* = 1、*β* = 0。

一个 LayerNorm 只有 2d 个参数，和动辄 d × d 的线性层比起来微不足道。

<Note kind="point">LayerNorm 对每个词的向量单独做：减去自己的均值、除以自己的标准差，再乘 γ、加 β。之后每个向量都回到统一的尺度，不管前面的层把数值推到多大。</Note>

## 为什么是“每个词”

注意，均值和方差是在**一个词的 d 个数**之间算的，每个词各算各的，叫“层”归一化，因为它对一层的所有维度做归一化。

还有一种更早的 BatchNorm（批归一化），方向正好相反：对**同一维**、在一个 batch 的**所有样本**之间算均值和方差。它在图像网络里很成功，但不适合语言模型：句子有长有短，batch 里的样本彼此差异很大；更麻烦的是，推理时一次可能只生成一个 token，没有“一批”可以算统计量。LayerNorm 只看当前这个词自己，和 batch 里有什么、有多少都无关，训练和推理的计算完全一样。

LayerNorm 还有一个有用的性质：**对输入的整体缩放和平移不敏感**。把 **x** 整体乘以 3，均值和标准差也都乘以 3，相除之后结果不变；整体加 5，均值也加 5，相减之后结果不变。所以前面的层输出的尺度怎么漂移，经过 LayerNorm 后都被抹平了。

## 放在哪里

在 TinyLM 里，LayerNorm 放在每个残差相加**之后**：

<div class="ai-formula"><b><i>x</i></b> ← LN(<b><i>x</i></b> + 注意力(<b><i>x</i></b>))，　<b><i>x</i></b> ← LN(<b><i>x</i></b> + FFN(<b><i>x</i></b>))</div>

这是 2017 年原始 Transformer 的做法，叫 **Post-Norm**（后归一化）。今天的大模型普遍换成了另一种位置：把 LayerNorm 放在子模块**之前**，残差流本身不归一化，叫 Pre-Norm；而且常用一个更简单的版本 RMSNorm，省掉了减均值那一步。为什么要这样改，第 36 讲会专门讨论。这一篇先按原始的结构，把整个 Transformer 搭完。

## 用代码复现

下面的代码手写了 LayerNorm，在 TinyLM“AI”那一行上逐步计算并和 `tinylm.json` 核对；验证它对整体缩放和平移不敏感；然后在 30 层的残差网络上比较归一化前后每层输出的长度。

```python
import json
import numpy as np

st = {s["key"]: np.array(s["v"]) for s in json.load(open("tinylm.json", encoding="utf-8"))["examples"]["34"]["steps"]}

def layer_norm(x, gamma=1.0, beta=0.0, eps=1e-5):
    mu = x.mean(axis=-1, keepdims=True)                      # ① 均值（每一行，也就是每个词各算各的）
    var = ((x - mu) ** 2).mean(axis=-1, keepdims=True)       # ② 方差
    return gamma * (x - mu) / np.sqrt(var + eps) + beta      # ③ 减均值、除以标准差 ④ 缩放、平移

# 1. TinyLM 第 1 层：“AI”残差相加之后的那一行
x = st["L1res1"][3]
mu, var = x.mean(), x.var()
print("x =", x.round(4), " 均值", round(mu, 4), " 方差", round(var, 4))
y = layer_norm(x)
print("LayerNorm：", y.round(4), " 新的均值", round(abs(y.mean()), 6), " 新的方差", round(y.var(), 4))
print("和 tinylm.json 一致：", np.allclose(y, st["L1ln1"][3], atol=1e-4))

# 2. 尺度不变：整行乘 3、或者加 5，结果不变
print("乘 3：", np.allclose(layer_norm(3 * x), y, atol=1e-5), "  加 5：", np.allclose(layer_norm(x + 5), y))

# 3. 30 层残差网络（ReLU），每层输出的长度：不归一化时一路变大，归一化后稳定
rng = np.random.default_rng(0)
d, L = 16, 30
Ws = rng.standard_normal((L, d, d)) / np.sqrt(d)
for use_ln in [False, True]:
    h, sizes = rng.standard_normal(d), []
    for W in Ws:
        h = h + np.maximum(0, h @ W)                         # 残差
        if use_ln:
            h = layer_norm(h)
        sizes.append(np.linalg.norm(h))
    print("归一化" + ("后" if use_ln else "前") + "：第 1、10、20、30 层输出的长度", [round(float(sizes[i]), 1) for i in [0, 9, 19, 29]])

# 4. 参数：γ 和 β 各 d 个
print("Llama-3-8B 一个归一化层的参数：", 4096, "个（RMSNorm 只有 γ）；每层 2 个，32 层加最后 1 个，共", (2 * 32 + 1) * 4096, "个")
```

输出：

LayerNorm： [-0.5327 -1.3091  0.5295  1.3123]  新的均值 0.0  新的方差 1.0
和 tinylm.json 一致： True
乘 3： True   加 5： True
归一化前：第 1、10、20、30 层输出的长度 [3.4, 42.9, 2006.4, 82441.6]
归一化后：第 1、10、20、30 层输出的长度 [4.0, 4.0, 4.0, 4.0]

前三行：“AI”那一行的均值 −0.0434、方差 0.4165，归一化后均值 0、方差 1，和 TinyLM 前向的结果一致。第四行：整体乘 3 或加 5，结果都不变。接下来两行：不归一化时，第 1、10、20、30 层输出的长度是 3.4、42.9、2006.4、82441.6；每层后加 LayerNorm，全都是 4.0。最后一行是下一节的数字。

## 到了大模型里

**参数很少，但每层都有。**Llama-3-8B 用的是 RMSNorm（第 36 讲），每个只有 *γ* 一个 4096 维的向量。每层有 2 个，32 层再加上输出层前面的最后一个，一共 65 个，合计 266240 个参数，在 80 亿里可以忽略。

**计算量很小，但不能省，也不能乱。**每个归一化都要先把一行的 4096 个数读一遍算统计量，再读一遍做归一化。它是访存密集型运算，通常和前面的残差相加、后面的矩阵乘法融合在一起做（第 74 讲）。它对数值精度也很敏感：求平方和时，几千个数加在一起很容易在低精度下溢出或丢失精度，所以即便模型用 BF16 计算，归一化内部通常也会用 FP32 累加（第 10 讲）。

## 容易混淆的地方

1. **LayerNorm 不改变形状，也不混合不同的词。**它是一行一行独立做的，“我”的归一化完全不受“爱”的影响。混合词与词的信息，只在注意力里发生。
2. **归一化之后不是所有数都在 −1 到 1 之间。**均值 0、方差 1 只是整体的统计量，单个数可以更大，比如上面的 1.3123。
3. **γ 和 β 是可训练的，和权重一起存在模型文件里。**在模型的权重列表里看到名字带 `norm` 或 `ln` 的小向量，就是它们。

## 回顾

残差网络的数值会一层层累积变大，30 层后可以到 8 万多。LayerNorm 对每个词的向量单独做归一化：减去这 d 个数的均值、除以标准差，再乘可训练的 *γ*、加 *β*，于是不管前面推到多大，每一层的输出都回到均值 0、方差 1、长度约 √d 的统一尺度。它只看当前这个词，所以和 batch 无关，训练和推理一样算；它对整体缩放和平移不敏感。原始 Transformer 把它放在每个残差相加之后（Post-Norm），现代模型改放在子模块之前并换成 RMSNorm，这是第 36 讲的内容。

到这里，Transformer 一层里的“注意力 → 残差 → 归一化”都讲完了。注意力让词与词交换了信息，之后每个词还要各自做一次计算：先升维、再降维，这就是前馈网络。它在做什么？为什么要先变宽再变窄？下一讲：**FFN 前馈网络**。
