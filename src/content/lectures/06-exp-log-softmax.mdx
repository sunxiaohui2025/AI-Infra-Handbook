大模型每生成一个词，最后一步都是一样的：给词表里的每个词打一个分（第 33 讲），分数越高，说明模型越觉得这个词该出现。可这些分数有正有负、可大可小，并不是概率。要从中抽一个词（下一讲），需要的是一组**概率**：每个都在 0 到 1 之间，加起来等于 1。

把任意一组分数变成概率的标准做法叫 **softmax**。它也出现在注意力里（第 26 讲）：把一组“相关程度”的打分变成加起来等于 1 的权重。这一讲先复习它要用到的指数和对数，再一步步算一次 softmax，最后看两个实用的问题：温度，以及数值的溢出。

## 指数：把任何数变成正数

指数函数 e<sup>x</sup>（e ≈ 2.718）有几个性质，正好是我们需要的：

- **永远是正数**：不管 x 是正是负，e<sup>x</sup> > 0。e<sup>0</sup> = 1，e<sup>−2</sup> ≈ 0.135，e<sup>2</sup> ≈ 7.39。
- **单调递增**：x 越大，e<sup>x</sup> 越大，所以不会打乱分数的大小顺序。
- **增长很快**：x 每加 1，e<sup>x</sup> 就乘以约 2.718。分数差 1，指数差 2.7 倍；差 3，就差 20 倍。
- **加法变乘法**：e<sup>a+b</sup> = e<sup>a</sup> · e<sup>b</sup>。

第一条解决了“分数有负数”的问题，第二条保证高分的词概率也高，第三条决定了 softmax 有多“偏心”。

## 对数：把乘法变回加法

对数 ln x（以 e 为底）是指数的反函数：ln(e<sup>x</sup>) = x。它只对正数有定义。对我们最有用的性质是

$$
\ln(a \cdot b) = \ln a + \ln b
$$

**乘法变加法。**一句话的概率是每个词的概率相乘（第 23 讲），4 个词分别是 0.4666、0.2、0.1、0.05，相乘得 0.000467；取对数相加得 −7.67，再取指数又回到 0.000467。概率都小于 1，对数都是负数，越不可能的事，对数越负。

为什么要绕这一圈？因为很多个小于 1 的数相乘，结果会小到计算机表示不了。1000 个 0.01 相乘，真实结果是 10<sup>−2000</sup>，可浮点数（第 10 讲）最小只能表示到 10<sup>−308</sup> 左右，直接算出来是 0；取对数相加，是 −4605.2，毫无问题。所以模型训练时算的都是**对数概率**，交叉熵损失（第 16 讲）就是负的对数概率。

## softmax：一步一步算

softmax 只有两步：**先取指数，再除以总和**。对一组分数 z<sub>1</sub>, …, z<sub>n</sub>：

$$
p_i = \frac{e^{z_i}}{\sum_{j=1}^{n} e^{z_j}}
$$

取指数让每个数变成正数，除以总和让它们加起来等于 1。

用 TinyLM 算一次。读到“我”之后，TinyLM 给 6 个词打的分是：我 1.64、爱 0.83、学 −0.39、AI −0.17、推理 −0.46、`<eos>` 0.37（TinyLM 的权重是随机的，这些分数没有意义，只用来演示计算）。

1. 取指数：5.155、2.293、0.677、0.844、0.631、1.448，总和 11.048。
2. 除以总和：**0.4666**、0.2076、0.0613、0.0764、0.0571、0.131。

六个数加起来正好是 1。“我”的分数最高，概率也最高，接近一半；分数最低的“推理”只有 5.7%。注意分数 1.64 和 0.83 只差 0.81，概率却差了一倍多，这就是指数“放大差距”的效果。

## 温度：控制分布有多尖

在取指数之前，先把所有分数除以一个数 T，叫**温度**：

$$
p_i = \frac{e^{z_i / T}}{\sum_{j} e^{z_j / T}}
$$

- **T = 1**：原始的 softmax。
- **T < 1**：分数之间的差距被放大，分布变**尖**。T = 0.5 时，“我”的概率从 0.467 升到 0.749。T 趋近 0 时，最高分的词概率趋近 1，相当于只选最高分。
- **T > 1**：差距被缩小，分布变**平**。T = 2 时，“我”降到 0.302，最低的“推理”升到 0.106。T 很大时，所有词的概率趋于相等。

生成文字时调的“温度”参数就是它（第 65 讲）：温度低，回答稳定、保守；温度高，回答更多样、也更容易出错。

## 两个实用的性质

**所有分数加同一个数，结果不变。**把每个 z<sub>i</sub> 都加上 c，分子分母都多乘了一个 e<sup>c</sup>，约掉了。代码验证了：所有打分加 100，概率完全不变。所以 softmax 只关心分数之间的**差**，不关心绝对的大小。

**用它来防止溢出。**如果分数很大，比如 1000，直接算 e<sup>1000</sup>，超出了浮点数能表示的范围，得到无穷大，再相除就出错了。利用上面的性质，先把每个分数都减去**最大的那个**，最大的变成 0、其余都是负数，指数都在 0 到 1 之间，绝不会溢出，而结果不变。softmax([1000, 999]) 这样算出来是 [0.7311, 0.2689]。所有的深度学习框架都是这样实现 softmax 的。

## 到了大模型里

**输出层：词表上的 softmax。**大模型最后对整个词表（Llama-3 有 128256 个词）做一次 softmax，得到下一个词的概率（第 33 讲）。

**注意力：每一行一次 softmax。**注意力的打分 `[b, h, s, s]`（第 5 讲）沿最后一维做 softmax，每个 token 对所有 token 的权重加起来等于 1（第 26 讲）。第 75 讲的 FlashAttention 要在“看不全一整行”的情况下算 softmax，靠的正是“减去最大值”这个性质的推广。

**训练时用对数概率。**框架通常把 softmax 和取对数合在一起算（log-softmax），既快又数值稳定，交叉熵损失直接用它。

## 用代码复现

下面的代码读取 TinyLM 读到“我”之后的打分，一步步算出 softmax，并和 `tinylm.json` 里存的概率对比；然后看温度的影响、平移不变性和防溢出；最后演示对数把乘法变成加法、避免下溢。

```python
import json
import numpy as np

ex = json.load(open("tinylm.json", encoding="utf-8"))["examples"]["16"]
vocab, z = ex["vocab"], np.array(ex["logits"][0])        # TinyLM 读到“我”之后，给 6 个词打的分
print("打分 z：", dict(zip(vocab, z.tolist())))

e = np.exp(z)                                            # 第一步：取指数，全部变成正数
print("e^z：", np.round(e, 3).tolist(), "，和 =", round(e.sum(), 3))
p = e / e.sum()                                          # 第二步：除以总和，加起来等于 1
print("softmax：", np.round(p, 4).tolist(), "，和 =", round(p.sum(), 6))
print("和 tinylm.json 里存的概率一致：", np.allclose(p, ex["p"][0], atol=1e-4))

def softmax(z, T=1.0):
    z = np.asarray(z, dtype=float) / T
    e = np.exp(z - z.max())                              # 先减去最大值，防止溢出，结果不变
    return e / e.sum()

for T in [0.5, 1.0, 2.0]:
    print(f"温度 T = {T}：", np.round(softmax(z, T), 3).tolist())

print("所有打分加 100，概率不变：", np.allclose(softmax(z + 100), p))
with np.errstate(over="ignore"):
    big = np.exp(np.float64(1000))                       # 超出 float64 的范围
print("直接算 e^1000：", big, "；减去最大值后 softmax([1000, 999]) =", np.round(softmax([1000, 999]), 4).tolist())

# 对数：把乘法变成加法。一句话 4 个词，每个词的概率相乘会越来越小，取对数后相加
probs = np.array([0.4666, 0.2, 0.1, 0.05])
print(f"概率相乘 {probs.prod():.6f}，对数相加 {np.log(probs).sum():.4f}，e^(对数和) = {np.exp(np.log(probs).sum()):.6f}")
print(f"1000 个 0.01 相乘：{np.prod(np.full(1000, 0.01))}（下溢成 0）；对数相加：{np.log(np.full(1000, 0.01)).sum():.1f}")
```

## 容易混淆的地方

1. **softmax 不是“最大值函数”。**它给每个选项都分一点概率，分数最高的拿得最多，但不是全部。它可以看作“软化了的 max”，这也是名字的由来；温度趋近 0 时才变成真正的“只取最大”。
2. **softmax 只看差值。**分数 (1, 2, 3) 和 (101, 102, 103) 得到的概率完全一样；但 (1, 2, 3) 和 (2, 4, 6) 不一样，乘以 2 相当于温度减半。
3. **对数概率是负数。**看到损失、困惑度里出现的负对数，不用奇怪：概率小于 1，对数自然是负的，加个负号后越小越好。

## 回顾

指数函数把任何数变成正数，保持大小顺序，并放大差距；对数把乘法变成加法，用来处理很多个概率相乘时的下溢。softmax 对一组分数先取指数再除以总和，得到加起来等于 1 的概率：TinyLM 读到“我”后的打分 1.64、0.83、−0.39……变成概率 0.4666、0.2076、0.0613……除以温度 T 再做 softmax，T 小分布变尖，T 大分布变平。所有分数同加一个数结果不变，所以实现时先减去最大值，防止溢出。大模型的输出层和注意力都靠 softmax。
