训练一个模型，说到底就是不断地微调它的参数，让预测越来越准（第 17 讲）。每调一次，都要回答一个核心问题：**如果把这个参数稍微调大一点点，最终的误差是变大还是变小、会变多少？**知道这个变化率，才能决定参数该往哪边改。

大模型有几十亿个参数，而且每个参数都藏在几十层嵌套的计算里面。这一讲复习微积分里最核心的三件事：导数是什么（一个变量），多个变量同时存在时怎么办（偏导数），以及函数一层套一层时怎么把变化率算出来（链式法则）。它们是第 18 讲反向传播的全部数学基础。

## 导数：变化有多快

函数 f(x) 在某一点的**导数**，说的是：当 x 在这一点附近轻轻挪动一点点时，f(x) 跟着变化的速度。在图像上，它就是曲线在这一点的**切线的斜率**。

怎么算这个斜率？取一个很小的步子 h，看 x 变成 x + h 时 f 变了多少，再除以 h：

$$
f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}
$$

这个比值其实是连接曲线上两点的**割线**的斜率。h 越小，两点靠得越近，割线就越贴近切线。

以 f(x) = x² 在 x = 3 为例：

- h = 0.1：(3.1² − 3²) / 0.1 = **6.1**；
- h = 0.01：**6.01**；
- h = 0.001：**6.001**。

h 越缩越小，比值越来越逼近 **6**。用求导公式算，x² 的导数是 2x，把 x = 3 代进去正好也是 6。

导数最实用的理解方式，把它看成一个**局部放大倍数**：在 x = 3 附近，x 增加一个极小的量 Δx（比如 0.001），f(x) 大约增加 6 × Δx（约 0.006）。导数为正，说明 x 增大时 f 也增大（上坡）；为负，说明 x 增大时 f 减小（下坡）；导数为 0，说明这一点附近是平的（往往是波峰或波谷）。

这门课里反复用到的几个基本导数，先列在这里备查：

| 函数 | 导数 | 用在哪里 |
| --- | --- | --- |
| xⁿ | n·xⁿ⁻¹ | 均方误差（n = 2 时导数是 2x） |
| eˣ | eˣ | softmax 里的指数 |
| ln x | 1/x | 交叉熵损失（第 16 讲） |
| sin x、cos x | cos x、−sin x | 位置编码与旋转 |
| sigmoid σ(x) = 1/(1 + e⁻ˣ) | σ(x)·(1 − σ(x)) | 门控与 SiLU 激活函数 |

## 偏导：多个变量时，只让一个动

模型的误差不可能只靠一个参数决定，而是同时取决于成千上万个参数。先看一个只有两个参数的最小例子：用直线 wx + b 去拟合一个数据点 (x, y) = (2, 7)，误差的平方是：

$$
L(w, b) = (w x + b - y)^2
$$

这里 x = 2、y = 7 是固定的数据，L 是 w 和 b 两个参数的函数。现在问“L 变化有多快”，必须先说清楚是让哪个参数在动。**偏导数** ∂L/∂w 的意思是：**把 b 死死按住不动（当成普通数字），只让 w 变化一点点**，L 变化的速度。

在 w = 1、b = 1 处算一下：wx + b − y = 2 + 1 − 7 = −4，所以 L = (−4)² = 16。
- 求 ∂L/∂w（把 b 当常数）：外层平方的导数是 2(wx + b − y)，里面对 w 求导得到 x，乘起来是 2·(wx + b − y)·x = 2 × (−4) × 2 = **−16**；
- 求 ∂L/∂b（把 w 当常数）：外层一样是 2(wx + b − y)，里面对 b 求导得到 1，乘起来是 2·(wx + b − y) = **−8**。

验证一下：让 w 加 0.01（b 不动），L 从 16 变成 (2.02 + 1 − 7)² = 15.8404，变化 −0.1596，正好约等于 −16 × 0.01。两个偏导数都是负的，说明把 w 和 b 往**增大**的方向调，误差 L 都会下降；而且 w 的偏导绝对值更大（16 对 8），调 w 降得更快。

把所有偏导数按顺序排成一个向量，就叫**梯度**：(∂L/∂w, ∂L/∂b) = (−16, −8)。第 17 讲会讲到，它指向 L 增长最快的方向，梯度下降就是沿着它的反方向走一小步。

## 链式法则：一层套一层，倍数相乘

神经网络是一层套一层的复合函数：输入经过第一层得到中间结果，中间结果经过第二层……最后才算出损失。前面的参数离最终结果隔着好几层，它动一点点，损失会变多少？

**链式法则**（chain rule）给出的答案非常直观：**一串影响接起来，总的放大倍数就是每一段放大倍数的乘积。**

看一个三步串联的例子：x → u = 3x + 1 → v = u² → y = ln v。我们来跟踪 x = 0.5 处发生的事：
- 先一路算过去：u = 3×0.5 + 1 = 2.5，v = 2.5² = 6.25，y = ln 6.25 = 1.8326。
- 再看每一步自己的局部放大倍数（局部导数）：
  1. 第一步 u = 3x + 1：du/dx = 3（x 变 Δ，u 变 3Δ）。
  2. 第二步 v = u²：dv/du = 2u = 5（u 变一点，v 变它的 5 倍）。
  3. 第三步 y = ln v：dy/dv = 1/v = 1/6.25 = 0.16（v 变一点，y 变它的 0.16 倍）。

现在想象我们把 x 轻轻推大 0.001：u 会跟着增加 0.001 × 3 = 0.003；接着 v 会增加 0.003 × 5 = 0.015；最后 y 会增加 0.015 × 0.16 = 0.0024。总的变化除以 0.001，放大倍数正好是：

$$
\frac{dy}{dx} = \frac{dy}{dv}\cdot\frac{dv}{du}\cdot\frac{du}{dx} = 0.16 \times 5 \times 3 = 2.4
$$

链式法则威力巨大的地方在于：**我们根本不需要把整个嵌套公式展开化简再求导**，只要把大函数拆成一连串简单的小步骤，算出每一步自己的局部导数，最后乘起来就行。第 18 讲的反向传播就是靠这个办法，把 80 亿参数的导数一次性算完的。

## 多条路径怎么办：分叉就相加

上面的链是一条单行线。实际的网络里，一个数常常同时送给后面的好几个地方（分叉），通过多条路径共同影响最终结果。比如 z = u·v，而 u 和 v 都依赖 x。

这时 x 变动 Δ，既会通过 u 让 z 变化一点，又会通过 v 让 z 变化一点，两条路的影响叠加在一起，所以总变化率是**各条路径的乘积之和**：

$$
\frac{dz}{dx} = \frac{\partial z}{\partial u}\cdot\frac{du}{dx} + \frac{\partial z}{\partial v}\cdot\frac{dv}{dx}
$$

记住这句口诀：**同一条路上的局部导数相乘，不同路径的影响相加。**第 29 讲的残差连接，正是靠“多修一条直通路径”让梯度可以直接加回来，避免越乘越小。

## 到了大模型里

**每个参数一个偏导。**Llama-3-8B 有 80 亿个参数，训练的每一步都要算出损失对每一个参数的偏导数，也就是一个 80 亿维的梯度。靠的就是链式法则和反向传播。

**梯度消失和爆炸。**链式法则是连乘。几十层的网络，如果每层的局部导数都小于 1（比如 sigmoid 的导数最大只有 0.25），连乘几十次就趋近于 0，前面的层几乎收不到更新信号（梯度消失）；如果每层都大于 1，连乘起来就会数值爆炸。激活函数的演进（第 14 讲）、残差连接（第 29 讲）、归一化（第 30 讲）都是为了驯服这串连乘。

**推理不需要导数。**导数只在训练改参数时才用。推理只做前向计算，不用存中间结果去算梯度，所以推理所需的显存和算力都远小于训练（第 99 讲）。

## 用代码复现

下面的代码用越来越小的 h 逼近 x² 在 3 处的导数；算 L = (wx + b − y)² 的两个偏导数并验证；算三步链的导数，和数值方法对比；最后看 sigmoid 的导数。

```python
import math

# 1. 导数 = 切线的斜率：f(x) = x² 在 x = 3 处，用越来越小的 h 去逼近
f = lambda x: x * x
for h in [0.1, 0.01, 0.001]:
    print(f"h = {h}：(f(3 + h) − f(3)) / h = {(f(3 + h) - f(3)) / h:.4f}")
print("公式 f′(x) = 2x，x = 3 时 = 6")

# 2. 偏导：L(w, b) = (w·x + b − y)²，x = 2，y = 7，在 w = 1、b = 1 处
x, y, w, b = 2.0, 7.0, 1.0, 1.0
L = lambda w, b: (w * x + b - y) ** 2
r = w * x + b - y
print(f"L = {L(w, b):.0f}；∂L/∂w = 2·(wx + b − y)·x = {2 * r * x:.0f}，∂L/∂b = 2·(wx + b − y) = {2 * r:.0f}")
print(f"w 加 0.01：L 从 {L(w, b):.4f} 变成 {L(w + 0.01, b):.4f}，变化 {L(w + 0.01, b) - L(w, b):.4f} ≈ −16 × 0.01")

# 3. 链式法则：x → u = 3x + 1 → v = u² → y = ln v
x = 0.5
u = 3 * x + 1; v = u ** 2; yv = math.log(v)
du, dv, dy = 3, 2 * u, 1 / v                             # 每一步的局部导数
print(f"x = {x} → u = {u} → v = {v} → y = {yv:.4f}")
print(f"dy/dx = (dy/dv)·(dv/du)·(du/dx) = {dy:.2f} × {dv:.1f} × {du} = {dy * dv * du:.2f}")
g = lambda x: math.log((3 * x + 1) ** 2)
print(f"数值验证：(g(0.5 + 1e-6) − g(0.5)) / 1e-6 = {(g(0.5 + 1e-6) - g(0.5)) / 1e-6:.4f}")

# 4. 几个常用的导数（深度学习里反复出现）
sig = lambda z: 1 / (1 + math.exp(-z))
z = 0.0
print(f"sigmoid 在 0 处：σ = {sig(z)}，σ′ = σ(1 − σ) = {sig(z) * (1 - sig(z))}")
```

输出：

```text
h = 0.1：(f(3 + h) − f(3)) / h = 6.1000
h = 0.01：(f(3 + h) − f(3)) / h = 6.0100
h = 0.001：(f(3 + h) − f(3)) / h = 6.0010
公式 f′(x) = 2x，x = 3 时 = 6
L = 16；∂L/∂w = 2·(wx + b − y)·x = -16，∂L/∂b = 2·(wx + b − y) = -8
w 加 0.01：L 从 16.0000 变成 15.8404，变化 -0.1596 ≈ −16 × 0.01
x = 0.5 → u = 2.5 → v = 6.25 → y = 1.8326
dy/dx = (dy/dv)·(dv/du)·(du/dx) = 0.16 × 5.0 × 3 = 2.40
数值验证：(g(0.5 + 1e-6) − g(0.5)) / 1e-6 = 2.4000
sigmoid 在 0 处：σ = 0.5，σ′ = σ(1 − σ) = 0.25
```

前四行是导数的逼近：6.1、6.01、6.001 → 6。接着两行是偏导数：∂L/∂w = −16、∂L/∂b = −8，w 加 0.01 时 L 变化 −0.1596。然后是链式法则：0.16 × 5 × 3 = 2.4，数值验证也是 2.4。最后是 sigmoid 在 0 处的导数 0.25。

## 容易混淆的地方

1. **导数是“局部”的。**它只描述这一点附近的变化率，离远了曲线一弯就不准了。所以梯度下降每次只能走一小步，走远了，梯度指的方向就不对了。
2. **偏导数要说清楚对谁。**∂L/∂w 和 ∂L/∂b 是不同的数；“L 的导数”这种说法在多变量时没有意义，要说“L 对 w 的偏导”。
3. **链式法则是乘，多路径是加。**同一条路径上的局部导数相乘，不同路径的贡献相加，两者不要混。

## 回顾

导数是函数在一点的变化率，几何上是切线的斜率，可以用割线斜率 (f(x+h) − f(x)) / h 在 h 趋近 0 时逼近：x² 在 3 处，h = 0.1、0.01、0.001 时依次是 6.1、6.01、6.001，导数是 6。多个变量时，偏导数只让一个变量动：L = (wx + b − y)² 在 w = b = 1 处，∂L/∂w = −16、∂L/∂b = −8，排成梯度。函数一层套一层时，链式法则把每一步的局部导数相乘：x → 3x + 1 → u² → ln v 在 x = 0.5 处，0.16 × 5 × 3 = 2.4。多条路径时，各条路径的贡献相加。这些是反向传播和训练的数学基础。
