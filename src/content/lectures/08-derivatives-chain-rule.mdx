训练一个模型，说到底就是不断地调整它的参数，让预测越来越准（第 17 讲）。每调一次，都要回答一个问题：**这个参数往哪个方向改、改多少，损失会下降？**要回答它，就得知道“参数变一点，损失会变多少”。这个“变化率”，就是导数。

大模型有几十亿个参数，每个参数都藏在一层套一层的计算里。这一讲复习三件事：导数是什么，多个变量时的偏导数，以及一层套一层时怎么算导数的链式法则。它们是第 18 讲反向传播的全部数学基础。

## 导数：变化有多快

函数 f(x) 在某一点的**导数**，说的是：x 在这一点附近变化一点点时，f 变化的速度。几何上，它就是曲线在这一点的**切线的斜率**。

怎么算？取一个很小的 h，看 x 变成 x + h 时 f 变了多少，除以 h：

$$
f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}
$$

这个比值是连接曲线上两点的**割线**的斜率。h 越小，两点越近，割线越接近切线。

以 f(x) = x² 在 x = 3 为例：

- h = 0.1：(3.1² − 3²) / 0.1 = **6.1**；
- h = 0.01：**6.01**；
- h = 0.001：**6.001**。

越来越接近 6。用求导公式，x² 的导数是 2x，x = 3 时正好是 6。

导数的意思是：x 从 3 增加一个很小的量 Δ，f 大约增加 6Δ。它是一个**放大倍数**：输入的小变化，在输出里被放大了多少倍。导数为正，f 随 x 增大而增大；为负，则减小；为 0，这一点附近是平的（可能是最低点或最高点）。

常用的几个导数，后面会反复用到：

| 函数 | 导数 |
| --- | --- |
| xⁿ | n·xⁿ⁻¹ |
| eˣ | eˣ |
| ln x | 1/x |
| sin x、cos x | cos x、−sin x |
| sigmoid σ(x) = 1/(1 + e⁻ˣ) | σ(x)·(1 − σ(x)) |

## 偏导：多个变量时，只让一个动

模型的损失取决于很多个参数。先看一个最简单的：用直线 wx + b 去拟合一个数据点 (x, y) = (2, 7)，损失是误差的平方：

$$
L(w, b) = (w x + b - y)^2
$$

现在 L 是 w 和 b 两个变量的函数。问“L 变化有多快”，要先说清楚是哪个变量在变。**偏导数** ∂L/∂w 的意思是：**b 保持不动，只让 w 变化一点点**，L 变化的速度。把 b 当常数，对 w 求导就行。

在 w = 1、b = 1 处，wx + b − y = 2 + 1 − 7 = −4，L = 16。

- ∂L/∂w = 2·(wx + b − y)·x = 2 × (−4) × 2 = **−16**；
- ∂L/∂b = 2·(wx + b − y) = **−8**。

验证一下：w 加 0.01，L 从 16 变成 15.8404，变化 −0.1596，约等于 −16 × 0.01。两个偏导数都是负的，说明把 w 和 b 往**增大**的方向调，损失会下降；而 w 的偏导绝对值更大，调 w 效果更明显。

把所有偏导数排成一个向量，叫**梯度**：(∂L/∂w, ∂L/∂b) = (−16, −8)。它指向 L 增长最快的方向。梯度下降（第 17 讲）就是沿梯度的反方向走一小步。

## 链式法则：一层套一层

神经网络是一层套一层的函数：输入经过第一层得到中间结果，中间结果经过第二层……最后得到损失。参数在前面的层里，它对损失的影响要经过后面的每一层才传到。

**链式法则**说：一串影响接起来，总的放大倍数就是每一段放大倍数的乘积。

看一个三步的例子：x → u = 3x + 1 → v = u² → y = ln v。在 x = 0.5 处：

- u = 2.5，v = 6.25，y = ln 6.25 = 1.8326。
- 每一步的局部导数：du/dx = 3，dv/du = 2u = 5，dy/dv = 1/v = 0.16。

x 变一点，u 变 3 倍那么多；u 变一点，v 变 5 倍那么多；v 变一点，y 变 0.16 倍那么多。所以 x 变一点，y 变

$$
\frac{dy}{dx} = \frac{dy}{dv}\cdot\frac{dv}{du}\cdot\frac{du}{dx} = 0.16 \times 5 \times 3 = 2.4
$$

数值验证：x 加 10⁻⁶，y 的变化除以 10⁻⁶，也是 2.4000。

链式法则的好处是：**不需要把整个复杂函数写出来求导**，只要知道每一步自己的局部导数，乘起来就行。每一步的局部导数都很简单（加法、乘法、平方、对数、激活函数），整个网络的导数就能一步步算出来。

## 多条路径怎么办

上面的链是一条直线。实际的网络里，一个变量常常通过好几条路径影响结果。比如 z = u·v，而 u、v 都依赖 x。这时 x 对 z 的影响是**各条路径的影响加起来**：

$$
\frac{dz}{dx} = \frac{\partial z}{\partial u}\cdot\frac{du}{dx} + \frac{\partial z}{\partial v}\cdot\frac{dv}{dx}
$$

路径上相乘，路径之间相加。第 18 讲的反向传播，就是把这个规则系统地应用到整张计算图上：从损失出发，沿着每条边往回乘局部导数，在分叉处把各条路径的贡献加起来。第 29 讲的残差连接，也正是靠“多了一条路径”让梯度更容易传回去。

## 到了大模型里

**每个参数一个偏导。**Llama-3-8B 有 80 亿个参数，训练的每一步都要算出损失对每一个参数的偏导数，也就是一个 80 亿维的梯度。靠的就是链式法则和反向传播。

**梯度消失和爆炸。**链式法则是连乘。几十层的网络，如果每层的局部导数都小于 1（比如 sigmoid 的导数最大只有 0.25），乘起来就趋近 0，前面的层几乎学不到东西（梯度消失）；都大于 1 则会爆炸。激活函数的选择（第 14 讲）、残差连接（第 29 讲）、归一化（第 30 讲）都和这个问题有关。

**推理不需要导数。**导数只在训练时用。推理只做前向计算，不用存中间结果去算梯度，所以推理比训练省得多（第 99 讲）。

## 用代码复现

下面的代码用越来越小的 h 逼近 x² 在 3 处的导数；算 L = (wx + b − y)² 的两个偏导数并验证；算三步链的导数，和数值方法对比；最后看 sigmoid 的导数。

```python
import math

# 1. 导数 = 切线的斜率：f(x) = x² 在 x = 3 处，用越来越小的 h 去逼近
f = lambda x: x * x
for h in [0.1, 0.01, 0.001]:
    print(f"h = {h}：(f(3 + h) − f(3)) / h = {(f(3 + h) - f(3)) / h:.4f}")
print("公式 f′(x) = 2x，x = 3 时 = 6")

# 2. 偏导：L(w, b) = (w·x + b − y)²，x = 2，y = 7，在 w = 1、b = 1 处
x, y, w, b = 2.0, 7.0, 1.0, 1.0
L = lambda w, b: (w * x + b - y) ** 2
r = w * x + b - y
print(f"L = {L(w, b):.0f}；∂L/∂w = 2·(wx + b − y)·x = {2 * r * x:.0f}，∂L/∂b = 2·(wx + b − y) = {2 * r:.0f}")
print(f"w 加 0.01：L 从 {L(w, b):.4f} 变成 {L(w + 0.01, b):.4f}，变化 {L(w + 0.01, b) - L(w, b):.4f} ≈ −16 × 0.01")

# 3. 链式法则：x → u = 3x + 1 → v = u² → y = ln v
x = 0.5
u = 3 * x + 1; v = u ** 2; yv = math.log(v)
du, dv, dy = 3, 2 * u, 1 / v                             # 每一步的局部导数
print(f"x = {x} → u = {u} → v = {v} → y = {yv:.4f}")
print(f"dy/dx = (dy/dv)·(dv/du)·(du/dx) = {dy:.2f} × {dv:.1f} × {du} = {dy * dv * du:.2f}")
g = lambda x: math.log((3 * x + 1) ** 2)
print(f"数值验证：(g(0.5 + 1e-6) − g(0.5)) / 1e-6 = {(g(0.5 + 1e-6) - g(0.5)) / 1e-6:.4f}")

# 4. 几个常用的导数（深度学习里反复出现）
sig = lambda z: 1 / (1 + math.exp(-z))
z = 0.0
print(f"sigmoid 在 0 处：σ = {sig(z)}，σ′ = σ(1 − σ) = {sig(z) * (1 - sig(z))}")
```

输出：

```text
h = 0.1：(f(3 + h) − f(3)) / h = 6.1000
h = 0.01：(f(3 + h) − f(3)) / h = 6.0100
h = 0.001：(f(3 + h) − f(3)) / h = 6.0010
公式 f′(x) = 2x，x = 3 时 = 6
L = 16；∂L/∂w = 2·(wx + b − y)·x = -16，∂L/∂b = 2·(wx + b − y) = -8
w 加 0.01：L 从 16.0000 变成 15.8404，变化 -0.1596 ≈ −16 × 0.01
x = 0.5 → u = 2.5 → v = 6.25 → y = 1.8326
dy/dx = (dy/dv)·(dv/du)·(du/dx) = 0.16 × 5.0 × 3 = 2.40
数值验证：(g(0.5 + 1e-6) − g(0.5)) / 1e-6 = 2.4000
sigmoid 在 0 处：σ = 0.5，σ′ = σ(1 − σ) = 0.25
```

前四行是导数的逼近：6.1、6.01、6.001 → 6。接着两行是偏导数：∂L/∂w = −16、∂L/∂b = −8，w 加 0.01 时 L 变化 −0.1596。然后是链式法则：0.16 × 5 × 3 = 2.4，数值验证也是 2.4。最后是 sigmoid 在 0 处的导数 0.25。

## 容易混淆的地方

1. **导数是“局部”的。**它只描述这一点附近的变化，离远了就不准了。所以梯度下降每次只能走一小步，走远了，梯度指的方向就不对了。
2. **偏导数要说清楚对谁。**∂L/∂w 和 ∂L/∂b 是不同的数；“L 的导数”这种说法在多变量时没有意义，要说“L 对 w 的偏导”。
3. **链式法则是乘，多路径是加。**同一条路径上的局部导数相乘，不同路径的贡献相加，两者不要混。

## 回顾

导数是函数在一点的变化率，几何上是切线的斜率，可以用割线斜率 (f(x+h) − f(x)) / h 在 h 趋近 0 时逼近：x² 在 3 处，h = 0.1、0.01、0.001 时依次是 6.1、6.01、6.001，导数是 6。多个变量时，偏导数只让一个变量动：L = (wx + b − y)² 在 w = b = 1 处，∂L/∂w = −16、∂L/∂b = −8，排成梯度。函数一层套一层时，链式法则把每一步的局部导数相乘：x → 3x + 1 → u² → ln v 在 x = 0.5 处，0.16 × 5 × 3 = 2.4。多条路径时，各条路径的贡献相加。这些是反向传播和训练的数学基础。
