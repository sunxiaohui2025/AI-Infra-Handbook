# AI Infra 学习网站

> 一套用大模型逐讲编写的 **AI 基础设施（LLM 推理）课程**，以可交互组件贯穿始终。

共 **5 章、14 篇、110 讲**，从「为什么模型要把一切变成数字」一直讲到能跑起来的迷你推理引擎。每讲只讲一个技术点，按依赖顺序排列——读到任何一讲时，它用到的概念都已在前面讲过。

本地网站用 **Astro 5 + MDX** 搭建，公式用 LaTeX，交互做成一个个可复用组件直接嵌进文章。

## 这个网站讲什么

一条主线贯穿全站：用 **一个玩具模型** 理解原理（手算、交互看得见每一步），用 **真实模型** 算工程账（显存、速度、成本）。这是 infra 视角和普通科普的区别——每讲都会落到它对显存、速度、成本的影响。

章节主线：**数学基础 → 大模型基础 → 单机推理 → 分布式推理 → 综合项目**。前两章打基础，后三章是推理优化的主体。

## 设计原则

- **一讲一个点**：开头能用一句话回答「它解决什么问题」。
- **从问题出发**：先演示没有它会出什么问题，再引出它本身。
- **一个例子贯穿全站**：同一个玩具模型从矩阵乘法一直用到完整前向传播。
- **落到工程**：每讲都说明它对显存、速度、成本的影响。
- **分主线与选读**：全站 95 讲主线；第 6 篇「训练全流程」和 8 讲选读可跳过，共 15 讲。
- **组件先行**：110 讲的交互归纳为 16 个可复用组件，组件服务多讲，而不是每讲单独开发。

## 学习路线

网站提供两条路线，可随时切换（记在浏览器里）：

- **完整路线**：按 01 → 110 顺序学。第三到第五章按每周 2 天约 22 周。
- **Infra 快速路线**：第一章只读 03、05、06、10、11；第二章跳过第 16–20 讲（训练相关）和整篇第 6 篇；其余照常。适合已有基础、想尽快进入推理优化的读者。

## 示例约定：数字从哪来

全站只用两套例子，读者在不同讲里反复见到同一组数字，前后就能对上。

**玩具模型 TinyLM**（用于第一、二章的手算和交互，矩阵小到能在屏幕上完整展示）：

| 参数 | 取值 |
| --- | --- |
| 词表 | 6 个 token：我、爱、学、AI、推理、`<eos>` |
| 隐藏维度 d | 4 |
| 注意力头数 | 2（每头维度 2） |
| FFN 隐藏维度 | 8 |
| 层数 | 2 |
| 序列长度 | 最长 4 |

同一组权重从「03 矩阵乘法」一直用到「34 完整前向传播」。所有数值由 `tinylm/tinylm.py` 算出，文章和组件都读取它的输出。

**真实模型**（用于第 5 篇和第三至五章的参数、显存、速度计算）：

| 模型 | 类型 | 关键配置 |
| --- | --- | --- |
| Llama-3-8B | 稠密、GQA | 32 层、隐藏 4096、32 个 Q 头、8 个 KV 头、head_dim 128、FFN 14336、词表 128256 |
| DeepSeek-V3 | MoE、MLA | 总参数约 671B、每 token 激活约 37B |

**硬件**：一张数据中心 GPU（如 H100）作主参照，DGX Spark 作实测机器；两者带宽相差约十倍，正好用来讲 Roofline。

## 本地运行

```bash
npm install
npm run dev      # 打开 http://localhost:4321
npm run build    # 生成静态站点到 dist/
npm run preview  # 本地预览构建结果
```

**页面**

- `/`：首页，学习路线图（5 章横排，两条路线可切换），顶部按讲名/问题/编号实时过滤。
- `/p/<篇>`：篇页，本篇学习目标 + 讲列表。
- `/l/<讲>`：文章页，正文 + 前置知识、上一讲/下一讲自动生成。
- `/search.json`：⌘K 搜索索引。

顶栏 `⌘K` 或 `/` 打开搜索；「完整路线 / Infra 快速路线」切换会记在浏览器里。

## 写作与开发工作流

内容由大模型逐讲生成，配套三个"三件套"保证全站统一：`写作规范.md`、玩具模型参数（`tinylm/tinylm.py`）、符号与术语表。

1. 每次只生成一讲：按大纲里该讲的「解决什么问题」和前置讲来写。
2. 数字必须跑代码：手算部分的每个数值都由脚本算出，文章引用脚本输出，避免手算出错。
3. 组件单独开发：文章里只引用组件和参数，组件在页面里开发和调试。
4. 人工审校三件事：「解决什么问题」是否讲清；用到的概念是否都在前面讲过；演示和代码里的数字是否都由脚本算出、前后一致。
5. 一份内容三处发布：网站文章是母版，公众号长文按篇合并，视频从交互演示里挑最有画面感的一讲来录。

**目录结构**

```
  components/               可复用交互组件
  pages/                    首页、篇页、文章页、搜索索引
  layouts/  styles/         布局与设计系统
```
