有了自注意力，我们可以开始搭 Transformer 了。一个大模型要叠很多层：Llama-3-8B 有 32 层，更大的模型有 80 层、120 层。第 15 讲说过，层数越多，网络能表达的东西越复杂。可是层数一多，就会碰到一个第 14 讲、第 18 讲都提过的难题：**梯度要一层一层地往回传，传得越远，越容易变得极小或极大，前面的层就训不动了。**

这一讲介绍解决它的关键部件：**残差连接**（residual connection）。它的做法简单得出人意料：每一层的输出，再加上这一层的输入。正是这一个加号，让几十层、上百层的网络变得可以训练。

## 一层一层乘下去

第 18 讲的反向传播告诉我们，梯度每往回经过一层，都要乘上这一层的“局部导数”。一个网络有 30 层，传到第 1 层时，梯度就是 30 个数（实际上是 30 个矩阵）连乘的结果。

先用最简单的数字感受一下。如果每一层的局部导数都是 0.5，乘 30 次是 0.5<sup>30</sup> ≈ 9.31 × 10<sup>−10</sup>，几乎是 0：前面的层收到的修正信号微乎其微，这叫**梯度消失**。如果每一层都是 1.5，乘 30 次是 1.92 × 10<sup>5</sup>，大得离谱，参数一步就被推飞，这叫**梯度爆炸**。只有每层都恰好在 1 附近，才能安全地传过 30 层，而这是很难保证的。

真实的网络里也是这样。下面的代码搭了一个 30 层、每层 16 维的网络，权重随机初始化，每层是“线性层 + 激活函数”。从最后一层传回一个长度为 1 的梯度：用 tanh 时，传到第 0 层只剩 0.0506；用 ReLU 时，干脆变成了 0，因为一路上总有神经元的输出是 0（第 14 讲的“死亡 ReLU”），梯度在那里被截断，30 层叠下来全断了。

## 给每一层开一条捷径

残差连接的做法是：一层不再直接输出 *F*(**x**)，而是输出

$$
\mathbf{x}_{l+1} = \mathbf{x}_l + F(\mathbf{x}_l)
$$

*F* 是这一层原本要做的计算（比如注意力，或者前馈网络），**x**<sub>l</sub> 是这一层的输入。也就是说，输入“绕过”这一层，原封不动地直接加到输出上。这条绕过去的路叫**捷径**（shortcut）或跳跃连接（skip connection）。

看一下导数。对 **x**<sub>l</sub> 求导，加号两边分别求：第一项 **x**<sub>l</sub> 的导数是 1，第二项是 *F* 的导数 *F*′：

$$
\frac{\partial \mathbf{x}_{l+1}}{\partial \mathbf{x}_l} = 1 + F^{\prime}
$$

这个“1”就是救命的关键。想象一下：哪怕这一层里的 ReLU 全部死亡、导致 *F*′ = 0，普通网络的梯度乘上 0 就彻底断死了；而加了残差连接后，这一层的局部导数是 1 + 0 = 1，梯度可以沿着捷径**原样直接穿过去**，丝毫不受阻挡。

还可以换一个角度看。把 30 个 (1 + *F*′) 连乘展开，会得到很多项：有一项是 1 × 1 × … × 1，对应“每一层都走捷径”的那条直通高速路；有的项里含一个 *F*′，对应“只在某一层走 *F*、其余都走捷径”的路……梯度是所有这些路径之和，其中总有很短的路径，不会因为连乘而消失。

<Note kind="point">残差连接：每层输出 = 输入 + 这一层的计算结果。导数里多了一个“1”，梯度可以沿着捷径直接传回前面的层，不会在层层连乘中消失。</Note>

几个值得试的操作：

- **切到 ReLU**：普通网络的曲线直接掉到图的最底下，梯度在某一层被截断成了 0；加残差的网络照样能把梯度传回去。
- **拖初始化系数**：普通网络对它非常敏感。用 tanh 时把系数调到 0.6，传到第 0 层的梯度就只剩 10<sup>−8</sup> 量级；残差网络在同样的设置下照样能传回来。
- **把层数拉到 60**：普通网络的问题更严重了。

但也要注意绿线的另一个特点：它不是平的，而是**往前越来越大**。代码里，用 tanh 时传到第 0 层是 19.57，用 ReLU 时是 3704.18。原因是残差网络的每一层都往信号上“加”东西，前向时信号越叠越大，反向时梯度也跟着越叠越大。所以光有残差还不够，还需要有东西把每一层的数值拉回一个稳定的范围。这就是下一讲的 LayerNorm。GPT-2 等模型还会在初始化时把每个残差分支的权重缩小一些，也是为了控制这种累积。

## 残差流：一条贯穿全网的主干

在 Transformer 里，每一层有两个子模块：注意力和前馈网络（第 31 讲），每个都带一个残差连接：

<div class="ai-formula"><b><i>x</i></b> ← <b><i>x</i></b> + 注意力(<b><i>x</i></b>)，　<b><i>x</i></b> ← <b><i>x</i></b> + FFN(<b><i>x</i></b>)</div>

可以把那个一路传下来的 **x** 想象成一条贯穿整个网络的“主干道”，叫**残差流**（residual stream）。每个子模块都做两件事：从主干道上读出当前的信息，算出一点“修改量”，再加回主干道上。词嵌入是主干道上最初的内容，每一层都往上面叠加一些新的东西：这个词和上下文的关系、它在句子里的语法角色、可能的下一个词……最后由输出层从主干道上读出结果。

这个视角说明了一个硬性要求：**子模块的输出必须和输入同样形状**，否则加不起来。所以注意力最后要乘 *W*<sub>o</sub> 回到 d 维（第 28 讲），前馈网络升维之后还要降回 d 维（第 31 讲）。TinyLM 第 1 层的第一个残差，就是把“AI”加了位置编码的向量 (0.541, −0.19, 0.43, 0.4)，和它的注意力输出 (−0.928, −0.698, −0.132, 0.404) 相加，得到 (−0.387, −0.888, 0.298, 0.804)。

这个视角也解释了残差为什么好训练：每一层只需要学“在已有的基础上改一点”，而不是从头变出一个全新的表示。刚初始化时，如果 *F* 的输出很小，整个网络就接近“什么都不做”，信号能顺畅地从头传到尾，训练从一个稳定的起点开始。

## 用代码复现

下面的代码先算了连乘的例子；再搭一个 30 层的网络，用 tanh 和 ReLU 分别比较普通网络和残差网络在第 0 层、第 15 层的梯度大小；最后从 TinyLM 的前向结果里取出第 1 层的第一个残差。

```python
import json
import numpy as np

# 1. 一个数一层层乘下去
print("每层乘 0.5，乘 30 层：", f"{0.5 ** 30:.2e}", "  每层乘 1.5，乘 30 层：", f"{1.5 ** 30:.2e}")

# 2. 30 层、每层 16 维的网络：从最后一层传回长度为 1 的梯度，看到第 0 层还剩多少
def grad_norms(L, act, residual, gain=1.0, d=16, seed=0):
    rng = np.random.default_rng(seed)
    Ws = rng.standard_normal((L, d, d)) * gain / np.sqrt(d)
    x, zs = rng.standard_normal(d), []
    for W in Ws:                                   # 前向
        z = x @ W
        zs.append(z)
        a = np.tanh(z) if act == "tanh" else np.maximum(0, z)
        x = x + a if residual else a
    g = np.eye(d)[0]                               # 最后一层收到的梯度
    norms = [1.0]
    for W, z in zip(Ws[::-1], zs[::-1]):           # 反向（第 18 讲）
        dz = g * (1 - np.tanh(z) ** 2 if act == "tanh" else (z > 0))
        back = W @ dz
        g = g + back if residual else back         # 残差：多一条原样传回的路
        norms.append(np.linalg.norm(g))
    return norms[::-1]                             # 第 0 层在最前

for act in ["tanh", "relu"]:
    p, r = grad_norms(30, act, False), grad_norms(30, act, True)
    print(f"{act:4s}  普通：第 0 层 {p[0]:.2e}，第 15 层 {p[15]:.2e}　｜　残差：第 0 层 {r[0]:.2f}，第 15 层 {r[15]:.2f}")

# 3. TinyLM 第 1 层的第一个残差：x + 注意力(x)，形状必须一样
st = {s["key"]: np.array(s["v"]) for s in json.load(open("tinylm.json", encoding="utf-8"))["examples"]["34"]["steps"]}
print("“AI”：", st["pos"][3].round(3), "+", st["L1attn"][3].round(3), "=", st["L1res1"][3].round(3))
print("每层的残差相加次数：2；Llama-3-8B 32 层共", 2 * 32, "次")
```

输出：

```text
每层乘 0.5，乘 30 层： 9.31e-10   每层乘 1.5，乘 30 层： 1.92e+05
tanh  普通：第 0 层 5.06e-02，第 15 层 3.27e-01　｜　残差：第 0 层 19.57，第 15 层 1.87
relu  普通：第 0 层 0.00e+00，第 15 层 0.00e+00　｜　残差：第 0 层 3704.18，第 15 层 37.20
“AI”： [ 0.541 -0.19   0.43   0.4  ] + [-0.928 -0.698 -0.132  0.404] = [-0.387 -0.888  0.298  0.804]
每层的残差相加次数：2；Llama-3-8B 32 层共 64 次
```

第一行是 0.5 和 1.5 连乘 30 次。接下来两行：tanh 时，普通网络的梯度传到第 0 层只剩 0.0506，残差网络是 19.57；ReLU 时，普通网络在第 0 层和第 15 层都是 0，残差网络分别是 3704.18 和 37.2。最后两行是 TinyLM 的残差相加和下一节的数字。演示和这里的随机数不同，具体数值会不一样，但趋势相同。

## 到了大模型里

**残差连接是深度网络的标配。**它最早出现在 2015 年的 ResNet（何恺明等人）里，让图像识别网络一下子从二十几层做到了一百五十多层。Transformer 原封不动地继承了它。Llama-3-8B 有 32 层，每层两次残差相加，一共 64 次。

**残差流的宽度就是隐藏维度。**Llama-3-8B 的残差流是 4096 维，每个 token 一路带着这 4096 个数穿过 32 层。注意力和前馈网络都从它读、往它写，所以 d 也被称为模型的“宽度”。

**残差相加本身很便宜，但要搬数据。**每次相加只是逐元素的加法，计算量可以忽略，但要把两个 [s, 4096] 的矩阵读进来、再写出去。和第 14 讲的激活函数一样，它是访存密集型运算，推理引擎通常把它和后面的归一化融合成一个算子（第 83 讲）。多卡用张量并行时，每个子模块的结果要先在卡之间合并（All-Reduce），再加回残差流（第 105 讲）。

## 容易混淆的地方

1. **残差是相加，不是拼接。**输入和输出逐元素相加，维度不变。如果把它们拼起来，每过一层维度就会翻倍。
2. **残差学的是“修改量”。**“残差”这个名字就来自这里：*F* 学的是“目标输出减去输入”的那部分差值，也就是残余的部分。
3. **残差不能单独解决所有问题。**它让梯度不会消失，但信号和梯度可能随着层数累积变大。实际的深层网络总是“残差 + 归一化 + 合适的初始化”一起用。

## 回顾

深层网络难训，是因为梯度要连乘几十个局部导数，很容易消失或爆炸：每层乘 0.5，30 层后只剩 10<sup>−9</sup>。残差连接让每层输出“输入 + *F*(输入)”，局部导数变成 1 + *F*′，梯度可以沿着捷径直接传回前面的层。在 30 层的网络上，用 ReLU 时普通网络的梯度传到第 0 层变成了 0，加了残差就能传回去。Transformer 的每层有两个残差：注意力和前馈网络各一个，它们一起构成了贯穿全网的残差流，所以每个子模块的输出都必须和输入同样形状。

不过实验也显示，残差网络的数值会一层层累积变大。怎么让每一层的输出都保持在一个稳定的尺度上？下一讲：**LayerNorm**。
