零件已经有了三样：分词器、嵌入、注意力。这一讲把剩下的零件补齐，组装成一个完整的 GPT：输入一串编号，输出每个位置对下一个 token 的打分。然后写一个最简单的生成循环，让它说出第一句话。

它说出来的会是一串乱码，因为还没有训练。但这一讲结束时，模型的结构就定型了：后面四讲的预训练、解码、装 GPT-2 权重、指令微调，用的都是这一讲的 `GPT` 类，一行都不再改。

## 还差哪几个零件

第 32 讲画过一个 Transformer Block 的结构。对照它，还差四样：

- **LayerNorm**（第 30 讲）：把每个 token 的 d 个数减去均值、除以标准差，再乘一组可学的缩放 γ、加一组平移 β。它让每一层的输入保持在相近的尺度上。
- **GELU**（第 14 讲）：GPT-2 用的激活函数。和 ReLU 的区别是负半轴不是一刀切成 0，而是平滑地趋近于 0。
- **前馈网络 FFN**（第 31 讲）：两个线性层夹一个 GELU，先从 d 维升到 4d 维，再降回 d。注意力负责“在位置之间搬运信息”，FFN 负责“在每个位置上加工信息”。
- **残差连接**（第 29 讲）：子层的输出加回到它的输入上，x + f(x)。网络深了，梯度可以沿着这条“直通”的路一路传回去。

组装的方式是 GPT-2 用的 **Pre-Norm**（第 36 讲）：先归一化，再进子层，再加残差。一个 Block 两个子层：

$$
x \leftarrow x + \text{Attn}(\text{LN}_1(x)),\qquad x \leftarrow x + \text{FFN}(\text{LN}_2(x))
$$

## 跑一遍

**LayerNorm**：[2, 4, 6, 8] 的均值是 5，方差是 5，归一化后是 [−1.342, −0.447, 0.447, 1.342]，均值 0、方差 1。

**GELU**：正半轴接近 x 本身（3 → 2.996），负半轴不是 0，而是一个小的负数：−1 → −0.159，−0.5 → −0.154，到 −3 已经几乎是 0。

**参数量**逐项对一下（第 35 讲的方法）：

- token 嵌入 4096 × 256 = 1,048,576，位置嵌入 256 × 256 = 65,536。
- 每层注意力 4d² + d = 262,400，FFN 8d² + 5d = 525,568，两个 LayerNorm 各 2d，共 1024。一层 788,992，4 层 3,155,968。
- 最后的 LayerNorm 512，输出层 256 × 4096 = 1,048,576。
- 合计 5,319,168，FP32 每个 4 字节，约 20 MiB。

一个反直觉的地方：**4 层 Transformer 只占 59%，两张和词表有关的表占了 39%。**模型越小，词表的份额越大。这也是上一讲把词表定为 4096 的原因：如果用 GPT-2 的 50,257，两张表就是 2570 万个参数，是 Transformer 部分的 8 倍。反过来，GPT-2 small 的 Transformer 部分有 8500 万个参数，词表那张表 3860 万，共用输出层能省下其中一份，这就是 1.63 亿变成“124M”的原因。我们的模型共用的话能省 105 万，约 20%；书里也没有共用，理由是分开训练效果略好。这里按书的做法，第 58 讲装 GPT-2 权重时，把同一份权重复制进输出层即可。

**形状**：“注意力机制”是 2 个 token（“注意力”“机制”各一个），输出 logits 是 [1, 2, 4096]。

**生成**：贪心生成 20 个 token，得到的是“底元就是这样最低]推理系统得很原本领亏……”。每个 token 本身都是语料里的词（分词器是训练过的），但模型的权重是随机的，它给 4096 个 token 的打分几乎没有规律，选出来的就是随机拼凑。

<Note kind="point">GPT = 嵌入 + L 个 Block + LayerNorm + 输出层。Block 是 Pre-Norm 的两个子层：x + Attn(LN(x))，x + FFN(LN(x))。整个模型只有一个接口：model(idx) 把 [B, T] 的编号变成 [B, T, V] 的打分。</Note>

## 检查

<RunOutput cmd=".venv/bin/python tests/check.py g3" file="minigpt/outputs/check_g3.txt" caption="图 55-3　g3 的检查：整个模型也是因果的，改第 10 个 token，前 10 个位置的输出一点不变。" />

上一讲检查了单个注意力层的因果性，这里检查整个模型：LayerNorm、FFN 都是逐位置的，残差也是逐位置的，所以只要注意力是因果的，整个模型就是因果的。这个检查能抓住一类隐蔽的错误：比如 LayerNorm 写成了在 T 维上求均值（`dim=1`），各个位置就混在一起了，形状照样对，只有这类检查能发现。

## 容易写错的地方

- **Post-Norm 和 Pre-Norm 混了。**原始 Transformer 是 LN(x + f(x))，GPT-2 是 x + f(LN(x))。两种都能跑，但装 GPT-2 权重时结构必须一致，否则输出完全不同。
- **位置嵌入用了 `torch.arange(T)` 却忘了 `device`。**模型在 GPU 上、位置编号在 CPU 上，查表时报错。
- **生成时没有截断到 T_max。**序列一长，位置嵌入查表越界，报 index out of range。

## 回顾

g3 补齐了 LayerNorm（γ、β，方差除以 d）、GELU（tanh 近似）、FFN（d → 4d → d）和 Pre-Norm 的 Transformer Block，组装成 `GPT`：嵌入 → 4 个 Block → LayerNorm → 输出层，5,319,168 个参数，其中 39% 在两张词表大小的表里。`generate_greedy` 每步把整段序列送进模型，取最后一个位置打分最高的 token。没训练过的模型，生成的是随机拼凑的词。

现在模型能给出打分了，但打分是随机的。怎么让它的打分变得有意义：给正确的下一个 token 打高分？要定义一个衡量“猜得多准”的数，再沿着让这个数变好的方向，一点点调整 530 万个参数。下一讲：**g4 · 预训练**。
