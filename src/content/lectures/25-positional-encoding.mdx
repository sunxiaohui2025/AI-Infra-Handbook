第 3 篇的小模型只看最后两个词。从这一篇开始，我们要搭一个能看到整段上下文的模型：Transformer。它的核心是下一讲的**自注意力**：每个词去“看”句子里的其他词，按相关程度把它们的信息收集过来。

不过在讲注意力之前，要先解决一个它自带的缺陷：**注意力本身不知道词的顺序**。“我爱你”和“你爱我”，在它眼里是同一堆词。第 22 讲也说过，嵌入里没有位置信息。这一讲回答：怎么把“第几个位置”这个信息告诉模型？答案是给每个位置也准备一个向量，加到词嵌入上，叫**位置编码**（positional encoding）。

## 注意力是“一袋词”

下一讲会细讲注意力的公式，这里只需要知道一件事：它给每个词算输出时，是根据**词的内容**去和其他词比较，决定从谁那里收集多少信息。公式里没有任何地方用到“这个词在第几个”。

结果是：把输入的词打乱顺序，输出也只是跟着同样地打乱，每个词得到的结果一个数都不变。下面的代码拿 TinyLM 验证了这一点：“我 爱 学 AI”倒过来变成“AI 学 爱 我”，算出来的四个输出向量，正好是原来那四个倒过来排。对注意力来说，句子就像一个装着词的袋子，顺序被完全丢掉了。

这对语言是致命的。“狗咬人”和“人咬狗”用的是同样三个字。

为了看清后果，我们训练了一个小模型（代码在 `tinylm.py` 的 `lecture_27`，第 26–28 讲会仔细拆开它）。它的任务是**复读**：输入“a b c 。”，a、b、c 是随机抽的三个词，然后它要接着把“a b c”再说一遍。要复读，模型在第二遍说到第 k 个词时，必须找到第一遍的第 k 个词，也就是**按位置**去找。训练好的模型，复读的正确率是 100%。把它的位置信息拿掉，正确率掉到 16.4%：它知道前面有哪几个词，却不知道哪个在前、哪个在后。

## 给每个位置一个向量

办法很直接：除了词嵌入表 *E*，再准备一张**位置编码表** *P*，第 p 行是“第 p 个位置”的向量，维度和词嵌入一样。每个 token 的输入，是它的词嵌入加上它所在位置的向量：

$$
\mathbf{x}_p = E[\mathrm{token}] + P[p]
$$

这样，同一个词出现在不同位置，输入的向量就不一样了；两个不同的词，也因为位置不同而带上了各自的“位置标签”。

*P* 怎么来？最简单的做法是把它也当成参数，和词嵌入一起训练出来，叫**可学习的位置嵌入**（learned positional embedding）。我们的复读模型就是这样：*P* 是一张 7 × 8 的表，随机初始化，训练中学出了各个位置的向量。GPT-2 也是这样做的。它的缺点是长度被表的大小写死了：表里只有 1024 行，就只能处理 1024 个 token，再长就没有对应的位置向量了。

## 正弦位置编码

2017 年提出 Transformer 的论文用了另一种不需要训练的位置编码，用正弦和余弦函数直接算出来：

<div class="ai-formula"><i>P</i>(p, 2i) = sin(p / 10000<sup>2i/d</sup>)，　<i>P</i>(p, 2i+1) = cos(p / 10000<sup>2i/d</sup>)</div>

p 是位置，d 是向量的维度，i 从 0 开始。向量的维度两两一组：第 0、1 维是一组，第 2、3 维是一组……每组用同一个“频率”，一个取 sin，一个取 cos。分母 10000<sup>2i/d</sup> 随着组号 i 增大而变大，所以越往后的组，随位置变化得越慢。

拿 TinyLM（d = 4）算一下。两组的分母分别是 10000<sup>0</sup> = 1 和 10000<sup>2/4</sup> = 100：

| 位置 p | sin(p) | cos(p) | sin(p/100) | cos(p/100) |
| --- | --- | --- | --- | --- |
| 0 | 0 | 1 | 0 | 1 |
| 1 | 0.841 | 0.540 | 0.010 | 1.000 |
| 2 | 0.909 | −0.416 | 0.020 | 1.000 |
| 3 | 0.141 | −0.990 | 0.030 | 1.000 |

前两维变化很快，每个位置都明显不同；后两维变化很慢，在 4 个位置里几乎不动。把这张表加到“我 爱 学 AI”的嵌入上，“我”变成 (0.7, 0.4, −0.9, 1.3)，“爱”变成 (0.541, 0.44, −0.79, 0.8)……每个词都被打上了位置的印记。

为什么要这样设计？可以把它想成一个由很多指针组成的钟表：最快的指针每走几步就转一圈，最慢的指针走几千步才转一圈。只看最快的指针，位置 0 和位置 6 差不多（sin 的周期约是 6.28），分不清；再看慢一些的指针，就分开了。所有指针合起来，每个位置的读数都独一无二。这和用二进制给数字编号是同一个道理：最低位每次都变，越高的位变得越慢。第 9 讲讲过的三角函数和旋转，正是这里的基础。

下面的演示画出了 d = 64 时，64 个位置的完整编码。每一行是一个位置，每一列是一维；左边几列（高频）条纹很密，右边几列（低频）几乎是一整片。选一个位置，右上方是它这一行的前 16 个数，右下方是它和每个位置的编码做点积的结果。

<PosEncoding caption="图 25-1　正弦位置编码。左：64 个位置 × 64 维，越往右的维度变化越慢。右下：位置 p 和其他位置的点积，在 p 处最大，离得越远一般越小。切换 d 看看维度少时会怎样。" />

右下那条曲线说明了正弦编码的一个好性质：**两个位置离得越近，编码越相似**。位置 10 和自己的点积是 32（d/2），和相隔 1 的位置是 30.92，相隔 5 是 23.5，相隔 30 是 17.07。模型因此能从编码里读出“这两个词离得有多远”。另一个好性质是，它对任何位置都能算，不受训练时长度的限制（当然，模型在没见过的长度上表现好不好，是另一回事）。

<Note kind="point">位置编码 = 每个位置一个向量，加到词嵌入上，让模型能区分词的顺序。可以训练出来（可学习的位置嵌入），也可以用不同频率的正弦、余弦直接算出来（正弦位置编码）。</Note>

## 用代码复现

下面的代码先验证注意力“不看顺序”；然后比较复读模型有和没有位置嵌入时的正确率；最后算出 d = 4 的正弦编码，加到 TinyLM 的嵌入上，并看 d = 64 时点积随距离的变化。

```python
import json
import numpy as np

t = json.load(open("tinylm.json", encoding="utf-8"))

# 1. 注意力不看顺序：把输入的行打乱，输出的行跟着同样地打乱，数值一个不变
X = np.array(t["examples"]["03"]["X"])               # “我 爱 学 AI”，4×4
L0 = t["weights"]["layers"][0]
Wq, Wk, Wv = (np.array(L0[k]) for k in ["W_q", "W_k", "W_v"])
def attention(X):                                   # 下一讲的主角，这里先当黑盒
    S = (X @ Wq) @ (X @ Wk).T / 2
    A = np.exp(S - S.max(1, keepdims=True)); A /= A.sum(1, keepdims=True)
    return A @ (X @ Wv)
perm = [3, 2, 1, 0]                                 # 倒过来：“AI 学 爱 我”
print("打乱后的输出 = 输出打乱：", np.allclose(attention(X[perm]), attention(X)[perm]))

# 2. 复读模型：有位置嵌入和没有位置嵌入
ex = t["examples"]["27"]
p = {k: np.array(ex[k]) for k in ["E", "P", "Wq", "Wk", "Wv", "Wo", "WU"]}
rng = np.random.default_rng(5)
tri = rng.integers(1, 14, (500, 3))                 # 500 组随机的三个词
seq = np.concatenate([tri, np.zeros((500, 1), int), tri], 1)   # a b c 。 a b c
def copy_predict(seq, use_pos):                      # 复读模型的前向，结构见第 26–28 讲
    T = seq.shape[1]
    x = p["E"][seq] + (p["P"][:T] if use_pos else 0)  # 词嵌入 + 位置嵌入
    Q, K, V = x @ p["Wq"], x @ p["Wk"], x @ p["Wv"]
    outs = []
    for h in range(2):                              # 两个头，每头 4 维
        s = slice(4 * h, 4 * h + 4)
        S = Q[..., s] @ K[..., s].transpose(0, 2, 1) / 2 + np.triu(np.full((T, T), -1e9), 1)
        A = np.exp(S - S.max(-1, keepdims=True)); A /= A.sum(-1, keepdims=True)
        outs.append(A @ V[..., s])
    return ((x + np.concatenate(outs, -1) @ p["Wo"]) @ p["WU"]).argmax(-1)
for use_pos in [True, False]:
    pred = copy_predict(seq, use_pos)[:, 3:6]
    print(("有" if use_pos else "没有") + "位置嵌入：复读正确率", np.mean(pred == seq[:, 4:7]))

# 3. 正弦位置编码
def sinusoid(n, d):
    pos = np.arange(n)[:, None]
    freq = 1 / 10000 ** (np.arange(0, d, 2) / d)    # 每两维一个频率
    P = np.zeros((n, d))
    P[:, 0::2], P[:, 1::2] = np.sin(pos * freq), np.cos(pos * freq)
    return P
print("d = 4，位置 0–3：")
print(np.round(sinusoid(4, 4), 3))
print("加到“我 爱 学 AI”上：")
print(np.round(X + sinusoid(4, 4), 3))

# 4. d = 64：位置 10 和相隔 k 的位置的点积，随距离变小
P64 = sinusoid(64, 64)
print({k: round(float(P64[10] @ P64[10 + k]), 2) for k in [0, 1, 2, 5, 10, 30]})
```

## 到了大模型里

位置编码的做法，经历了三代：

| 做法 | 代表模型 | 特点 |
| --- | --- | --- |
| 正弦位置编码 | 原始 Transformer（2017） | 不用训练，直接相加 |
| 可学习的位置嵌入 | GPT-2、BERT | 训练出来，长度被表的大小限制 |
| 旋转位置编码 RoPE | Llama、DeepSeek 等 | 不加到输入上，而是在注意力里旋转 Q 和 K |

今天的主流是第 37 讲要讲的 **RoPE**。它保留了正弦编码“不同频率”的思想，但不是把位置向量加到词嵌入上，而是在算注意力时，把每个词的 Q、K 向量按位置旋转一个角度，让两个词的点积只和它们的**相对距离**有关。Llama-3-8B 的 config 里那个 `rope_theta` 参数，就是这一讲公式里的 10000（Llama-3 把它调大到了 500000，让低频的“指针”转得更慢，以支持更长的上下文）。

对推理系统来说，位置也是一个需要小心处理的细节。生成时，每个新 token 的位置等于前面已有的 token 数；把不同长度的请求凑成一批时，每个请求的位置要各算各的，不能混。推理引擎里专门有一个叫 position ids 的输入来记录这件事。

## 容易混淆的地方

1. **位置编码是加上去的，不是拼上去的。**位置向量和词嵌入维度相同，直接相加，向量的长度不变。一个向量里同时混着“是什么词”和“在哪个位置”两种信息，由后面的层自己去分辨。
2. **位置指的是 token 的序号。**“我爱学AI”如果被切成 4 个 token，位置就是 0、1、2、3，和字数无关。
3. **有了位置编码，注意力本身还是不看顺序的。**注意力的公式没有变，变的是输入：因为每个词的向量里已经带了位置，“按内容比较”时，位置也自然成了比较的一部分。复读模型就是靠这个，找到了“第一遍的第 k 个词”。

## 回顾

自注意力按内容比较词与词，对顺序完全不敏感：打乱输入，输出只是跟着打乱。所以要在输入里加入位置：给每个位置一个和词嵌入同样长的向量，加到词嵌入上。这个向量可以训练出来（GPT-2），长度受表的大小限制；也可以用正弦、余弦直接算出来（原始 Transformer）：不同的维度对应不同的频率，像快慢不同的钟表指针，合起来给每个位置一个独一无二、并且近处相似的编码。我们的复读模型，有位置嵌入时全对，拿掉后只剩 16.4%。今天的大模型用的是它的升级版 RoPE。

现在，每个 token 的向量里既有“是什么”，也有“在哪里”。下一讲进入 Transformer 的核心：每个词怎么根据这些向量，去决定该看句子里的哪些词、从它们那里拿走什么。下一讲：**自注意力**。
