上一讲用 softmax 把模型的打分变成了概率：TinyLM 读到“我”之后，下一个词是“我”的概率 0.4666，“爱”0.2076，“学”0.0613，AI 0.0764，“推理”0.0571，`<eos>` 0.131。

接下来要真的选出一个词，接在后面，再去生成下一个（第 24 讲）。最简单的做法是每次都选概率最大的那个。可这样同一个问题永远得到同一个回答，而且常常会陷入重复。大模型通常**按概率随机抽**：概率 0.47 的词，大约一半的时候被选中；概率 0.06 的词，偶尔也会被选中。

“按概率随机抽”在计算机里到底怎么做？抽 100 次，结果会是什么样？这一讲讲概率分布和采样的基本概念。

## 概率分布

一个**概率分布**说的是：一件事有哪几种可能的结果，每种结果的可能性有多大。对“下一个词”来说，可能的结果就是词表里的每一个词，可能性就是 softmax 给出的概率。它要满足两个条件：每个概率都在 0 到 1 之间；所有概率加起来等于 1。

结果只有有限个（或可数个）、每个都有一个概率的分布叫**离散分布**，大模型输出的就是离散分布。另一类是**连续分布**，比如“0 到 1 之间的任意实数，取到每一段的可能性和这一段的长度成正比”，叫 **[0, 1) 上的均匀分布**。下面马上会看到，有了均匀分布，就能从任何离散分布里抽样。

## 怎么按概率抽

计算机能直接提供的随机数，是 [0, 1) 上均匀分布的随机数 u（比如 Python 的 `random.random()`）。用它来抽一个词，做法是：

1. **算累积概率**：把概率依次加起来。“我”0.4666，“我+爱”0.6742，再加“学”0.7355，再加 AI 0.8119，再加“推理”0.869，全部加完是 1。
2. **把 [0, 1) 切成几段**：[0, 0.4666) 归“我”，[0.4666, 0.6742) 归“爱”，[0.6742, 0.7355) 归“学”……每一段的长度正好等于那个词的概率。
3. **抽一个 u，看它落在哪一段**：u = 0.3 落在第一段，选“我”；u = 0.7 落在第三段，选“学”；u = 0.95 落在最后一段，选 `<eos>`。

因为 u 在 [0, 1) 上均匀分布，它落在某一段的可能性等于这一段的长度，也就是那个词的概率。这样就实现了“按概率抽”。

## 抽多了，频率就接近概率

单独抽一次，结果是随机的。可抽很多次之后，每个词被选中的**频率**会越来越接近它的**概率**。这叫**大数定律**。代码用固定的随机种子抽了三组：

- **抽 10 次**：“我”的频率 0.3，“爱”0.3，AI 一次都没抽到，和概率差得很远。
- **抽 100 次**：“我”0.42，“爱”0.19，大致接近了。
- **抽 10000 次**：“我”0.468，“爱”0.206，“学”0.064……和概率只差千分之几。

这提醒我们两件事：一是用模型生成一次回答，看到的只是一次抽样的结果，不能代表模型的全部倾向；二是评测模型时，常常要对同一个问题生成多次、统计结果（第 49、51 讲）。

## 随机种子

计算机里的“随机数”其实是用一个确定的公式算出来的一串数，看起来没有规律，叫**伪随机数**。公式的起点叫**随机种子**。种子相同，产生的随机数序列就相同，抽样结果也就完全一样。

代码里的 `np.random.default_rng(0)` 就固定了种子 0，所以每次运行，抽 10 次的结果都是同样的那一组。调试、复现实验时，固定种子很有用；推理服务里，一般每个请求用不同的种子，有的 API 允许用户自己指定种子，以便复现同一个回答。

## 贪心和采样

**贪心解码**：每次都选概率最大的词，这里永远是“我”。结果确定、稳定，但容易单调、重复。

**采样**：按概率抽。结果多样，但也可能抽到概率很低、不太合适的词。

两者之间有很多折中的办法：先用温度（第 6 讲）把分布变尖或变平，或者只在概率最大的几个词里抽（Top-k、Top-p）。这些是第 73 讲解码策略的内容。

## 分布有多“确定”：熵

有的分布很集中（一个词占了 99%），有的很分散（每个词都差不多）。衡量这一点的量叫**熵**：

$$
H = -\sum_i p_i \ln p_i
$$

只有一个词可能时，熵为 0（完全确定）；n 个词完全均匀时，熵最大，等于 ln n。这里 6 个词的分布，熵是 **1.479**，最大可能是 ln 6 = 1.792，说明它比较分散。熵也和交叉熵损失、困惑度紧密相关（第 16 讲）。

## 用代码复现

下面的代码读取 TinyLM 读到“我”之后的分布，算出累积概率，演示几个 u 落在哪一段；然后用固定的种子各抽 10、100、10000 次，统计频率；最后看贪心的结果和分布的熵。

```python
import json
import numpy as np

ex = json.load(open("tinylm.json", encoding="utf-8"))["examples"]["16"]
vocab, p = ex["vocab"], np.array(ex["p"][0])            # 第 6 讲算出的概率：读到“我”之后，下一个词的分布
print("分布：", dict(zip(vocab, p.tolist())), "，和 =", round(p.sum(), 4))

cdf = np.cumsum(p)                                       # 累积概率：把 [0, 1) 切成 6 段，每段的长度就是概率
print("累积：", np.round(cdf, 4).tolist())

def sample(u):                                           # 抽一个 [0, 1) 里均匀的随机数 u，看它落在哪一段
    return vocab[int(np.searchsorted(cdf, u, side="right"))]
for u in [0.3, 0.7, 0.95]:
    print(f"  u = {u} → {sample(u)}")

rng = np.random.default_rng(0)                           # 固定随机种子：每次运行抽到的结果都一样
for n in [10, 100, 10000]:
    draws = [sample(u) for u in rng.random(n)]
    freq = [draws.count(w) / n for w in vocab]
    print(f"抽 {n:5d} 次的频率：", np.round(freq, 3).tolist())

print("贪心（总取概率最大的）：", vocab[int(p.argmax())])
H = -(p * np.log(p)).sum()
print(f"熵 = {H:.3f}（6 个词均匀分布时最大，ln 6 = {np.log(6):.3f}；只有一个词时为 0）")
```

输出：

```text
分布： {'我': 0.4666, '爱': 0.2076, '学': 0.0613, 'AI': 0.0764, '推理': 0.0571, '<eos>': 0.131} ，和 = 1.0
累积： [0.4666, 0.6742, 0.7355, 0.8119, 0.869, 1.0]
  u = 0.3 → 我
  u = 0.7 → 学
  u = 0.95 → <eos>
抽    10 次的频率： [0.3, 0.3, 0.1, 0.0, 0.1, 0.2]
抽   100 次的频率： [0.42, 0.19, 0.08, 0.05, 0.06, 0.2]
抽 10000 次的频率： [0.468, 0.206, 0.064, 0.074, 0.062, 0.127]
贪心（总取概率最大的）： 我
熵 = 1.479（6 个词均匀分布时最大，ln 6 = 1.792；只有一个词时为 0）
```

第一、二行是分布和累积概率；接下来三行是 u = 0.3、0.7、0.95 各选中哪个词；然后是三组抽样的频率，次数越多越接近概率；最后是贪心的结果和熵。

## 容易混淆的地方

1. **概率高不等于一定被选中。**“我”的概率 0.47，意思是大约一半的时候被选中，另一半的时候选的是别的词。
2. **频率不等于概率。**频率是抽样的结果，会随抽样次数波动；概率是分布本身的性质。只有抽样次数足够多时，两者才接近。
3. **“随机”是可以复现的。**固定随机种子，同样的程序会得到同样的“随机”结果；换了种子或者换了运行环境（比如不同的 GPU 并行顺序），结果才会变。

## 回顾

概率分布描述一件事有哪些可能的结果、每种结果的可能性有多大，模型输出的下一个词的概率就是一个离散分布。按概率抽样的方法是：算累积概率，把 [0, 1) 切成长度等于各个概率的几段，抽一个均匀随机数 u，落在哪段选哪个。TinyLM 读到“我”后，u = 0.3 选“我”，u = 0.7 选“学”。抽得越多，频率越接近概率：抽 10 次差得很远，抽 10000 次“我”的频率是 0.468。随机种子决定了伪随机数序列，固定它就能复现结果。贪心总选概率最大的，采样按概率抽；熵衡量分布有多分散，这个分布的熵是 1.479。
