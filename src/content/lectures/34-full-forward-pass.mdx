从第 21 讲的分词开始，我们一站一站地造好了语言模型的每个部件。上一讲讲完了最后一站。这一讲不引入任何新东西，只做一件事：**让一句话真正走完全程**。“我 爱 学 AI”这 4 个编号从入口进去，经过 TinyLM 的两层 Transformer，从出口出来变成下一个词的概率。一路上有 24 站，每一站的每个数都可以查看。

走完这一遍，你看到的就是大模型每一次推理时发生的全部事情。Llama-3-8B 和它的区别，只是更宽（4096 维）、更深（32 层）、词表更大（128256 个词），以及第 5 篇要讲的几处改进。

## 全程的 24 站

TinyLM 的配置：词表 6 个词，d = 4，2 层，每层 2 个注意力头（每头 2 维），FFN 中间层 8 维，结构是原始 Transformer 的 Post-Norm（第 32 讲）。输入是“我 爱 学 AI”的编号 [0, 1, 2, 3]。

| 站 | 做什么 | 形状 | 详见 |
| --- | --- | --- | --- |
| 1 | 查嵌入表 | [4] → [4, 4] | 第 22 讲 |
| 2 | 加正弦位置编码 | [4, 4] | 第 25 讲 |
| 3 | 第 1 层：算 Q、K、V | 3 个 [4, 4] | 第 26 讲 |
| 4 | 两个头的注意力权重（带因果掩码） | 2 个 [4, 4] | 第 27、28 讲 |
| 5 | 两个头拼接、乘 *W*<sub>o</sub> | [4, 4] | 第 28 讲 |
| 6 | 残差相加 | [4, 4] | 第 29 讲 |
| 7 | LayerNorm | [4, 4] | 第 30 讲 |
| 8 | FFN 升维 | [4, 8] | 第 31 讲 |
| 9 | ReLU | [4, 8] | 第 14 讲 |
| 10 | FFN 降维 | [4, 4] | 第 31 讲 |
| 11 | 残差相加 | [4, 4] | 第 29 讲 |
| 12 | LayerNorm：第 1 层的输出 | [4, 4] | 第 30 讲 |
| 13–22 | 第 2 层：同样的 10 站，换一套权重 | [4, 4] | 第 32 讲 |
| 23 | 乘 lm_head：logits | [4, 6] | 第 33 讲 |

从第 2 站到第 22 站，数据的形状始终是 [4, 4]：4 个词、每个 4 维，只有 FFN 中间短暂地变宽到 8 维。这正是残差流（第 29 讲）：一条宽度固定的主干道，每一站都从它读、往它写。

## 跟着“AI”走一遍

挑几站看看“AI”这个词的变化。

- **第 1、2 站**：查表得到 (0.4, 0.8, 0.4, −0.6)，加上第 3 个位置的编码 (0.141, −0.99, 0.03, 1.0)，变成 (0.541, −0.19, 0.43, 0.4)。
- **第 4 站**：它是最后一个词，可以看全部 4 个词。在头 1 里它分给 4 个词的权重是 0.262、0.253、0.247、0.238，在头 2 里是 0.271、0.263、0.24、0.226，都比较平均，因为 TinyLM 没有训练过。（这里的输入加了位置编码，所以和第 28 讲只用嵌入算出的数字不同。）
- **第 6、7 站**：注意力的输出加回去，再归一化，得到 (−0.533, −1.309, 0.53, 1.312)。这就是第 30 讲手算过的那一行。
- **第 8–10 站**：FFN 里 8 个神经元亮了 4 个，降维后得到 (2.828, 1.673, 2.837, −0.636)，第 31 讲算过。
- **第 22 站**：两层结束，“AI”的最终向量是 (−1.142, −0.838, 1.12, 0.86)。
- **第 23、24 站**：乘 lm_head、softmax，“推理”的概率最高，0.441（第 33 讲）。

所以 TinyLM 对“我 爱 学 AI”之后的预测是“推理”。权重是随机的，这个预测没有意义；但整个计算过程，和一个训练好的大模型完全相同。

<Note kind="point">一次前向 = 查表 + 位置编码 → N 个 Transformer Block（每个：注意力、残差、归一化、FFN、残差、归一化）→ lm_head → softmax。大模型的每一次推理都是这一串计算。</Note>

## 前缀的预测，就藏在整句里

再看一个第 27 讲埋下的伏笔。把整句“我 爱 学 AI”送进去，得到 4 行概率；再只送前缀“我 爱”进去，得到 2 行。下面的代码会验证：**只送“我 爱”时的最后一行，和送整句时的第 2 行，完全相同。**

原因是因果掩码：第 2 个位置在每一层里都只能看第 1、2 个词，后面跟着“学 AI”还是什么都没有，对它毫无影响。这说明了两件事。第一，训练时一次前向的 4 行输出，确实是 4 道独立、合法的“猜下一个词”的题（第 23 讲）。第二，生成时前面那些词的计算结果永远不变，可以缓存（第 27 讲的 KV Cache）。

## 一个词一个词地生成

把前向传播放进第 24 讲的循环，TinyLM 就能“说话”了。从“我”开始，每次取概率最大的词接回去：

1. “我”→ 预测“推理”（0.360）
2. “我 推理”→ 预测“我”（0.582）
3. “我 推理 我”→ 预测“推理”（0.343）

生成的是“我 推理 我 推理”。没有意义，还有点重复，这正是一个没训练过的模型该有的样子。注意每一步都做了一次完整的前向。这里每一步都把整句从头算一遍；用上 KV Cache，每一步就只需要算新来的那一个词。

## 用代码复现

下面的代码用不到 30 行写出了 TinyLM 的完整前向：入口、两层 Block、出口，并和逐站计算的结果核对；然后验证“前缀的最后一行 = 整句的对应行”；最后从“我”开始贪心生成到 4 个词。

```python
import json
import numpy as np

t = json.load(open("tinylm.json", encoding="utf-8"))
vocab, E, layers, W_lm = t["config"]["vocab"], np.array(t["weights"]["embedding"]), t["weights"]["layers"], np.array(t["weights"]["lm_head"])

def sinusoid(n, d):                                        # 第 25 讲
    pos, freq = np.arange(n)[:, None], 1 / 10000 ** (np.arange(0, d, 2) / d)
    P = np.zeros((n, d)); P[:, 0::2], P[:, 1::2] = np.sin(pos * freq), np.cos(pos * freq)
    return P

def layer_norm(x, eps=1e-5):                               # 第 30 讲
    mu = x.mean(-1, keepdims=True)
    return (x - mu) / np.sqrt(((x - mu) ** 2).mean(-1, keepdims=True) + eps)

def softmax(z):
    e = np.exp(z - z.max(-1, keepdims=True)); return e / e.sum(-1, keepdims=True)

def forward(tokens, log=False):
    ids = [vocab.index(w) for w in tokens]
    x = E[ids] + sinusoid(len(ids), 4)                     # 入口：嵌入 + 位置编码
    s = len(ids); mask = np.triu(np.full((s, s), -np.inf), 1)
    for L in layers:                                       # 2 层 Transformer Block
        Q, K, V = (x @ np.array(L[k]) for k in ["W_q", "W_k", "W_v"])
        heads = []
        for h in range(2):                                 # 2 个头，每头 2 维，因果掩码
            c = slice(2 * h, 2 * h + 2)
            heads.append(softmax(Q[:, c] @ K[:, c].T / np.sqrt(2) + mask) @ V[:, c])
        x = layer_norm(x + np.concatenate(heads, 1) @ np.array(L["W_o"]))         # 残差 + LN
        x = layer_norm(x + np.maximum(0, x @ np.array(L["W_1"])) @ np.array(L["W_2"]))   # FFN + 残差 + LN
        if log:
            print("  一层之后：", x.shape)
    return softmax(x @ W_lm)                               # 出口：lm_head + softmax

print("“我 爱 学 AI”：")
p = forward(["我", "爱", "学", "AI"], log=True)
print("  概率", p.shape, "最后一行：", {w: round(float(v), 3) for w, v in zip(vocab, p[-1])})
st = {s["key"]: np.array(s["v"]) for s in t["examples"]["34"]["steps"]}
print("  和逐站结果一致：", np.allclose(p, st["probs"], atol=1e-3))

# 因果掩码：只输入前缀“我 爱”，最后一行和整句的第 2 行一模一样
p2 = forward(["我", "爱"])
print("前缀“我 爱”的最后一行 = 整句的第 2 行：", np.allclose(p2[-1], p[1]))

# 贪心生成：从“我”开始，每步取概率最大的词接回去（TinyLM 最长 4 个词）
seq = ["我"]
while len(seq) < 4:
    q = forward(seq)[-1]
    seq.append(vocab[int(q.argmax())])
    print(f"  第 {len(seq) - 1} 步：前 {len(seq) - 1} 个词 → “{seq[-1]}”（{q.max():.3f}）")
print("生成：", " ".join(seq))
```

## 到了大模型里

**同样的计算，更大的数字。**Llama-3-8B 一次前向：128256 个词的嵌入表查表；32 层，每层是 RMSNorm、32 头的注意力（带 RoPE 和 GQA）、残差、RMSNorm、SwiGLU FFN、残差；最后一个 RMSNorm、4096 × 128256 的 lm_head 和 softmax。每个 token 约要 2 × 80 亿 = 160 亿次浮点运算，下一讲会把这笔账算细。

**推理引擎就是在优化这一串计算。**第三章要讲的几乎所有技术，都可以放回这张 24 站的表里看：KV Cache 让第 3 站的 K、V 不必重算（第 61 讲）；FlashAttention 让第 4、5 站不必把整个注意力矩阵写进显存（第 75 讲）；算子融合把第 6、7 站这样的小操作合并起来（第 74 讲）；量化让第 3、8、10 站这些大矩阵乘法读更少的字节（第 11 篇）；张量并行把每一站的矩阵切到多张卡上（第 93 讲）。

**这一讲的 TinyLM 就是第五章的起点。**第五章的迷你推理引擎，会从一个像这样的朴素前向开始，一步步加上这些优化，并测出每一步带来的加速。

## 容易混淆的地方

1. **前向传播和推理不完全是一回事。**一次前向是“给一串 token，算出每个位置的概率”；推理（生成）是把前向放进循环，每次选一个词接回去，一共做很多次前向（prefill 一次、decode 很多次）。
2. **训练也要做这一遍前向。**训练时先做完全相同的前向，再算损失、做反向传播（第 18 讲）。推理只有前向，没有反向。
3. **TinyLM 的预测没有意义。**它的权重是随机的，生成的句子是乱的。这一讲关心的是计算过程，不是结果。

## 回顾

一句话的完整前向传播：编号查嵌入表、加位置编码，进入第一层；每层先做多头注意力、残差、LayerNorm，再做 FFN、残差、LayerNorm；两层之后乘 lm_head 得到 logits，softmax 得到每个位置下一个词的概率。全程 24 站，数据始终是 [4, 4] 的残差流，只在 FFN 中间变宽、在出口处变成 [4, 6]。TinyLM 预测“我 爱 学 AI”之后是“推理”；因为因果掩码，前缀“我 爱”的预测和整句的第 2 行完全一样；放进循环，它生成了“我 推理 我 推理”。Llama-3-8B 的每一次推理，都是同样的计算，只是规模大得多。

规模大到什么程度？一个模型的参数是怎么一项项加出来的，处理一个 token 到底要多少次浮点运算，序列变长时又会怎样？下一讲把这笔账算清楚：**参数量与计算量**。
