读大模型的代码或论文，到处是这样的注释：`x: [b, s, d]`、`q: [b, h, s, d_h]`、`scores: [b, h, s, s]`。第 3 讲的矩阵是两个数描述的一张表：几行、几列。这里却有三个、四个数。它们是什么？一个运算之后，形状为什么会变成那样？

这一讲讲**张量**和它的**形状**。它不涉及新的数学，只是把“一串数”“一张表”推广到更多的维度，再约定几条运算时形状怎么变的规则。可这些规则是读懂大模型代码最常用的工具：看一个运算，先看形状，往往就明白了它在做什么。

## 从数到张量

先把熟悉的东西排一排：

- 一个数，比如 0.7，叫**标量**，形状是 `[]`（没有维度）。
- 一串数，比如第 1 讲“我”的向量 (0.7, −0.6, −0.9, 0.3)，是**向量**，形状 `[4]`：一个维度，长度 4。
- 一张表，比如第 3 讲 4 个词叠成的 X，是**矩阵**，形状 `[4, 4]`：两个维度，4 行 4 列。

再往上，就是把好几张表叠起来。比如一次处理 2 句话，每句 4 个词、每个词 4 维，就是 2 张 4 × 4 的表叠在一起，形状 `[2, 4, 4]`。这种任意维度的“数的阵列”，统称**张量**（tensor）。标量、向量、矩阵都是张量的特例：0 维、1 维、2 维。

**形状**就是每个维度的长度，按顺序写成一个列表。维度的个数叫**阶**或**维数**（这里的“维”和“4 维向量”的“维”意思不同：后者说的是向量有几个分量）。

## [b, s, d] 读作什么

大模型里最常见的形状是 `[b, s, d]`（全站的符号约定）：

<dl class="ai-defs"><dt>b</dt><dd>批大小（batch）：一次同时处理几个序列（几句话、几个请求）</dd><dt>s</dt><dd>序列长度（sequence）：每个序列有几个 token</dd><dt>d</dt><dd>隐藏维度：每个 token 用几维的向量表示</dd></dl>

一个形状为 `[b, s, d]` 的张量，要用三个下标取出一个数：`x[i, j, t]` 是第 i 个序列、第 j 个 token 的向量的第 t 个分量。只给前两个下标，`x[i, j]`，取出的是一整个 d 维的向量；只给第一个，`x[i]`，取出的是第 i 句话的 `[s, d]` 矩阵。

用 TinyLM 举例：一批 2 句话，“我 爱 学 AI”和“AI 爱 学 推理”。先分词得到编号（第 21 讲），形状 `[2, 4]`：第一句是 [0, 1, 2, 3]，第二句是 [3, 1, 2, 4]。再查嵌入表（第 22 讲）把每个编号换成一个 4 维向量，就得到形状 `[2, 4, 4]` 的 x。x[1, 3] 是第 2 句第 4 个词“推理”的向量 (0.7, 0.3, −0.8, −0.4)。

## 运算之后形状怎么变

大模型里用到的张量运算，形状的变化可以归成几条规则。

**矩阵乘法只看最后两维。**第 3 讲的规则是 `[m, k] @ [k, n] → [m, n]`。对更高阶的张量，矩阵乘法作用在最后两维上，前面的维度都当作“一批”，一一对应地算：

<div class="ai-formula">[..., m, k] @ [..., k, n] → [..., m, n]</div>

比如 x 是 `[2, 4, 4]`，W 是 `[4, 4]`：x @ W 得到 `[2, 4, 4]`，相当于两句话各自做一次第 3 讲的矩阵乘法。第一句算出的结果，和第 3 讲的 C 完全一样。

**reshape：换一种看法。**`reshape` 只改变形状，不改变数据和它们的顺序。比如把 `[2, 4, 4]` 改成 `[2, 4, 2, 2]`：每个 token 的 4 维向量被看成 2 组、每组 2 个数。多头注意力（第 28 讲）就是这样把 d 维拆成 h 个头、每头 d<sub>h</sub> 维的（d = h · d<sub>h</sub>）。

**transpose：交换两个维度。**`[2, 4, 2, 2]` 交换第 1、2 维（从 0 数起）变成 `[2, 2, 4, 2]`，也就是 `[b, h, s, d_h]`：现在每个头的 4 个 token 排在一起了，每个头可以独立地算注意力。再做 q @ kᵀ（最后两维 `[s, d_h] @ [d_h, s]`），就得到每个头里两两的打分 `[b, h, s, s]` = `[2, 2, 4, 4]`。

**逐元素运算：形状不变。**两个形状相同的张量相加、相乘，或者对每个元素算激活函数，形状不变。

**归约：沿哪一维，哪一维消失。**对 `[2, 4, 4]` 沿最后一维求和（`sum(axis=-1)`），得到 `[2, 4]`：每个 token 的 4 个分量加成一个数；沿第 1 维（token）求平均，得到 `[2, 4]`：每句话的 4 个 token 平均成一个向量。softmax（第 6 讲）、归一化（第 30 讲）都要指定沿哪一维做。

## 广播：形状不同也能相加

第 13 讲的线性层要给 `[s, d]` 的结果加上一个偏置 **b**，形状 `[d]`，两者形状不同。约定的做法是**广播**（broadcasting）：把小的那个自动复制到每一个位置上，再逐元素相加。

规则是从**最后一维**开始对齐比较：

1. 两个张量的最后一维要么相等，要么其中一个是 1；
2. 再看倒数第二维，依此类推；
3. 维数少的那个，前面缺的维度当作 1；
4. 长度为 1 的维度，被复制到和另一个一样长。

所以 `[2, 4, 4] + [4]`：最后一维 4 和 4 相等；`[4]` 前面缺的两维当作 1，复制成 `[2, 4, 4]`。效果就是同一个 bias 加到每句话的每个 token 上。代码验证了 q[1, 2] + b 和 (q + b)[1, 2] 完全一样。

广播在大模型里到处都是：注意力的掩码 `[s, s]` 加到打分 `[b, h, s, s]` 上（第 27 讲），归一化的缩放参数 `[d]` 乘到 `[b, s, d]` 上（第 30 讲）。它省去了显式的复制，也不占额外的显存。

<Note kind="point">张量是任意维度的数的阵列，形状是每一维的长度。大模型最常见的是 [b, s, d]：b 个序列、每个 s 个 token、每个 d 维。矩阵乘法作用在最后两维，前面的维度一一对应；reshape 换看法不动数据，transpose 交换维度；逐元素运算形状不变，沿哪一维归约哪一维就消失；形状不同时按广播规则从最后一维对齐。</Note>

## 形状决定了大小

张量占多少内存，就是形状里所有数的乘积，再乘以每个数的字节数（第 10 讲）。换成 Llama-3-8B 的尺寸（一批 8 个请求、每个 2048 个 token、d = 4096、32 个头）：

- 一层的输入 `[8, 2048, 4096]`：6700 万个数，BF16 下 **134 MB**。
- 注意力的打分 `[8, 32, 2048, 2048]`：BF16 下 **2.1 GB**，只是一层的一个中间结果。

后者里出现了 s × s，序列越长，增长得越快。这是第 84 讲 FlashAttention 要解决的问题。习惯了看形状，这类问题一眼就能发现。

## 用代码复现

下面的代码用 NumPy 和 TinyLM 的数据，把演示里的步骤走一遍，打出每一步的形状；最后算 Llama-3-8B 尺寸下两个张量的大小。（先在 `tinylm/` 目录运行一次 `python tinylm.py`。）

```python
import json
import numpy as np

tl = json.load(open("tinylm.json", encoding="utf-8"))
vocab, E = tl["config"]["vocab"], np.array(tl["weights"]["embedding"])     # 词表 6 个词，嵌入表 [6, 4]
W = np.array(tl["examples"]["03"]["W"])                                     # 第 3 讲那个 4×4 的权重矩阵

# 一批 2 句话，每句 4 个词：先变成编号，形状 [b, s] = [2, 4]
sents = [["我", "爱", "学", "AI"], ["AI", "爱", "学", "推理"]]
ids = np.array([[vocab.index(w) for w in s] for s in sents])
print("编号 ids：", ids.shape, ids.tolist())

x = E[ids]                                        # 查表：每个编号换成一个 4 维向量 → [b, s, d]
print("查嵌入表 x：", x.shape, "，x[1, 3] 是第 2 句第 4 个词“推理”的向量", x[1, 3].tolist())

q = x @ W                                         # 最后一维和 W 相乘：[2, 4, 4] @ [4, 4] → [2, 4, 4]
print("乘权重 q = x @ W：", q.shape, "，和第 3 讲的 C 一样：", np.allclose(q[0], np.array(tl["examples"]["03"]["C"]), atol=0.006))

h, dh = 2, 2                                      # 拆成 2 个头，每头 2 维
qh = q.reshape(2, 4, h, dh).transpose(0, 2, 1, 3) # [b, s, d] → [b, s, h, dh] → [b, h, s, dh]
print("拆成多头：", q.shape, "→", q.reshape(2, 4, h, dh).shape, "→ 交换第 1、2 维", qh.shape)

scores = qh @ qh.transpose(0, 1, 3, 2)            # [b, h, s, dh] @ [b, h, dh, s] → [b, h, s, s]
print("每个头里两两打分：", scores.shape)

b = np.array([0.1, 0.2, 0.3, 0.4])                # 广播：[2, 4, 4] + [4]，b 被复制到每句话的每个词上
print("加偏置（广播）：", (q + b).shape, "，q[1, 2] + b 和 (q + b)[1, 2] 一样：", np.allclose(q[1, 2] + b, (q + b)[1, 2]))
print("对最后一维求和：", q.sum(axis=-1).shape, "；对第 1 维（词）求平均：", q.mean(axis=1).shape)

# 换成 Llama-3-8B 的尺寸：一批 8 个请求、每个 2048 个 token、d = 4096、32 个头
B, S, D, H = 8, 2048, 4096, 32
print(f"Llama-3-8B：一层的输入 [b, s, d] = [{B}, {S}, {D}]，{B * S * D / 1e6:.0f}M 个数，BF16 {B * S * D * 2 / 1e6:.0f} MB；"
      f"注意力打分 [b, h, s, s] = [{B}, {H}, {S}, {S}]，{B * H * S * S * 2 / 1e9:.1f} GB")
```

输出：

```text

查嵌入表 x： (2, 4, 4) ，x[1, 3] 是第 2 句第 4 个词“推理”的向量 [0.7, 0.3, -0.8, -0.4]
乘权重 q = x @ W： (2, 4, 4) ，和第 3 讲的 C 一样： True
拆成多头： (2, 4, 4) → (2, 4, 2, 2) → 交换第 1、2 维 (2, 2, 4, 2)
每个头里两两打分： (2, 2, 4, 4)
加偏置（广播）： (2, 4, 4) ，q[1, 2] + b 和 (q + b)[1, 2] 一样： True
对最后一维求和： (2, 4) ；对第 1 维（词）求平均： (2, 4)
```

## 容易混淆的地方

1. **“4 维向量”和“4 维张量”不是一回事。**前者是有 4 个分量的一串数，形状 `[4]`；后者有 4 个维度，比如 `[2, 2, 4, 2]`。说的时候最好直接说形状。
2. **reshape 和 transpose 不能互换。**`[s, h, d_h]` reshape 成 `[h, s, d_h]` 只是把同一串数重新切分，数据会错位；要让每个头的 token 排在一起，必须 transpose。
3. **广播是从右往左对齐的。**`[4, 4] + [4]` 是给每一行加，不是给每一列加；要给每一列加，需要把它写成 `[4, 1]`。

## 回顾

张量是任意维度的数的阵列：标量、向量、矩阵是 0、1、2 维的特例。形状是每一维的长度，`[b, s, d]` 表示 b 个序列、每个 s 个 token、每个 token d 维，`x[i, j]` 是第 i 个序列第 j 个 token 的向量。矩阵乘法作用在最后两维，前面的维度当作批；reshape 只换看法，transpose 交换维度；逐元素运算形状不变，归约让那一维消失；形状不同时按广播规则从最后一维对齐。TinyLM 一批 2 句经过嵌入、乘权重、拆头、打分，形状从 `[2, 4]` 变到 `[2, 2, 4, 4]`。张量的大小等于形状的乘积乘以每个数的字节数，Llama-3-8B 的一层输入就有 134 MB。

形状为 `[b, h, s, s]` 的注意力打分，每个数都是一个“分数”，有正有负、可大可小。模型最后要的却是“概率”：都在 0 到 1 之间，加起来等于 1。怎么把任意一组分数变成概率？下一讲：**指数、对数与 softmax**。
