到目前为止，句子里的每个词都是一个孤立的向量：“苹果”查表查出来的永远是同一行，不管它出现在“我吃苹果”还是“苹果发布了新手机”里。可一个词的意思，取决于它周围的词。第 3 篇的小模型只能看最后两个词，也是同样的问题。

这一讲介绍 Transformer 的核心部件：**自注意力**（self-attention）。它让句子里的每个词都能去“看”其他所有词，判断哪些词和自己有关，再把这些词的信息按相关程度收集过来，更新自己的向量。整个过程只用到我们学过的东西：矩阵乘法（第 3 讲）、点积（第 2 讲）和 softmax（第 6 讲）。我们先用 TinyLM 把每一步算一遍，再看一个训练过的模型，它的注意力真正学会了“看哪里”。

## 查询、键、值

先打个比方。你去图书馆找资料，心里有一个**问题**（我想找关于什么的书）；每本书的书脊上有一个**标签**（这本书讲什么）；书里是它的**内容**。你拿问题和每本书的标签比一比，越对得上的书，你越仔细地读它的内容；最后你脑子里得到的，是各本书内容按“对得上的程度”加权混合的结果。

自注意力里，每个词同时扮演这三个角色，各用一个向量表示：

- **查询**（query，**q**）：我在找什么样的信息。
- **键**（key，**k**）：我能提供什么样的信息，用来和别人的查询比对。
- **值**（value，**v**）：如果别人看我，我交给他的具体内容。

这三个向量都从这个词自己的向量 **x** 算出来，各乘一个权重矩阵（就是三个第 13 讲的线性层，不带偏置）：

<div class="ai-formula"><i>Q</i> = <i>X</i> · <i>W</i><sub>q</sub>，　<i>K</i> = <i>X</i> · <i>W</i><sub>k</sub>，　<i>V</i> = <i>X</i> · <i>W</i><sub>v</sub></div>

*X* 是整句话的嵌入，每行一个词（第 22 讲）。TinyLM 的 *X* 是“我 爱 学 AI”的 4 × 4 矩阵，三个权重矩阵也都是 4 × 4，所以 *Q*、*K*、*V* 都是 4 × 4，每一行是一个词的 q、k 或 v。第 3 讲算的 *X* · *W*，其实就是这里的 *Q* = *X* · *W*<sub>q</sub>：“我”的 q 是 (−0.34, 0.18, −0.16, 0.11)。

为什么要分成三个向量，而不是直接用 **x** 去比？因为“我在找什么”和“我能提供什么”通常是两回事。比如一个代词“它”，它要找的是前面出现过的名词，而它自己能提供的，是“这里有一个代词”这样的信息。三个不同的矩阵，让模型可以分别学习这三种角色。

## 打分：q 和 k 的点积

有了 q 和 k，每个词就可以给句子里的每个词打分：拿自己的 q 和对方的 k 做点积。第 2 讲说过，点积越大，两个向量越“对得上”。

以“我”为例。它的 q 和“我”自己的 k = (0.64, −0.27, −1.73, 0.8) 做点积：

$$
(-0.34)\times 0.64 + 0.18\times(-0.27) + (-0.16)\times(-1.73) + 0.11\times 0.8 = -0.2176 - 0.0486 + 0.2768 + 0.088 = 0.0986
$$

和“爱”“学”“AI”的 k 做点积，分别是 0.142、−0.0606、−0.1876。4 个词各给 4 个词打分，一共 16 个分数，排成一个 4 × 4 的矩阵，正好就是 *Q* 乘以 *K* 的转置：

<div class="ai-formula"><i>S</i> = <i>Q</i> · <i>K</i><sup>T</sup>，　<i>S</i><sub>ij</sub> = 第 i 个词的 q · 第 j 个词的 k</div>

*K*<sup>T</sup> 把 *K* 的行变成列，按第 3 讲的“行乘列”，*Q* 的第 i 行和 *K*<sup>T</sup> 的第 j 列做点积，就是 q<sub>i</sub> · k<sub>j</sub>。一次矩阵乘法，算完了所有词两两之间的分数。

## 缩放、softmax、加权求和

分数还不能直接用，还有三步。

**缩放。**把每个分数除以 √*d*<sub>k</sub>，*d*<sub>k</sub> 是 q 和 k 的维度。TinyLM 里 *d*<sub>k</sub> = 4，除以 2：“我”的四个分数变成 0.0493、0.071、−0.0303、−0.0938。原因下一节专门说。

**softmax。**对每一行做 softmax（第 6 讲），把分数变成加起来等于 1 的权重。“我”这一行得到

<div class="ai-formula">“我”分给 我、爱、学、AI 的权重 = 0.262，0.268，0.242，0.227</div>

这一行叫“我”的**注意力权重**：“我”在更新自己时，各个词分别占多大比重。所有行排在一起，就是 4 × 4 的注意力矩阵 *A*。

**加权求和。**用权重把各个词的 v 加起来，就是这个词的输出：

<div class="ai-formula">“我”的输出 = 0.262 · v<sub>我</sub> + 0.268 · v<sub>爱</sub> + 0.242 · v<sub>学</sub> + 0.227 · v<sub>AI</sub> = (−0.361, −0.12, −0.005, −0.175)</div>

四个词一起算，就是 *A* 乘 *V*。把这几步写成一个式子，就是 Transformer 论文里最有名的公式：

$$
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\left(\frac{QK^{T}}{\sqrt{d_k}}\right)\cdot V
$$

<Note kind="point">自注意力 = 每个词用自己的 q 和所有词的 k 做点积打分，缩放后 softmax 变成权重，再用权重把所有词的 v 加起来。一句话里所有词同时这样做，就是两次矩阵乘法加一次 softmax。</Note>

下面的演示把这些都摆了出来。左边是注意力矩阵 *A*，颜色越深权重越大；右边是 *X*、*Q*、*K*、*V*。点 *A* 的某一行，下方会逐步写出这一行的计算：q、打分、缩放、softmax、加权求和。

<AttentionView model="tiny" caption="图 26-1　TinyLM 的自注意力（一个头，d_k = 4）。每行的权重都在 0.2 到 0.3 之间，分得很平均：TinyLM 的权重是随机的，还没有学会该看谁。" />

你会发现每一行的权重都差不多，在 0.2 到 0.3 之间。这不是算错了：TinyLM 的权重是随机生成的，从来没训练过，q 和 k 之间没有什么有意义的对应关系，分数都很接近 0，softmax 之后就差不多平均分配了。注意力“看哪里”，是训练出来的。

## 为什么要除以 √d<sub>k</sub>

第 14、16 讲说过，softmax 在输入差距很大时会“饱和”：最大的那个几乎拿走全部权重，其余接近 0，梯度也随之消失。点积恰好有这个风险。

如果 q 和 k 的每个分量都是均值 0、方差 1 的随机数，它们的点积是 *d*<sub>k</sub> 个乘积的和，方差是 *d*<sub>k</sub>，标准差是 √*d*<sub>k</sub>。维度越高，分数的波动越大。代码里实际模拟了一下：*d*<sub>k</sub> = 4 时点积的标准差是 2，64 时约 8，128 时约 11。一个 q 对 8 个 k 打分后直接 softmax，128 维时最大的那个平均能拿到 0.92 的权重，几乎是一边倒；除以 √*d*<sub>k</sub> 后，分数的标准差回到 1 左右，最大权重降到 0.38，分布柔和得多，训练也更稳定。Llama-3 每个头的 *d*<sub>k</sub> 是 128，这一步缩放是必需的。

## 训练过的注意力长什么样

为了看到“学会了看哪里”的注意力，我们用上一讲的**复读模型**。它的输入是“a b c 。 a b c”，任务是在句号之后把 a、b、c 复读一遍。每个位置的输入是词嵌入加位置嵌入（8 维），注意力有两个头（第 28 讲细讲，这里先看第 1 个头），而且只能看自己和前面的词（第 27 讲细讲）。

<AttentionView model="copy" caption="图 26-2　训练过的复读模型（头 1）。第 4、5、6 行（句号和第二遍的 a、b）的权重几乎全部集中在第 1、2、3 个词上：要复读下一个词，就去看第一遍对应的那个词。换几个词试试，图案不变。" />

注意第 4、5、6 行。第 4 个位置是句号“。”，它要预测的下一个词是 a，于是它把约 1.0 的权重放在了第 1 个词 a 上；第 5 个位置（第二遍的 a）要预测 b，权重集中在第 2 个词 b 上；第 6 个位置要预测 c，权重集中在第 3 个词 c 上。每个位置都精确地“回头看 3 格”，把那里的词拿过来，复读出去。下方是模型对每个位置下一个词的预测，第二遍的三个全对。

用上面的下拉框换成别的词，比如“推理 鱼 你”，权重图案几乎不变：这个头学到的是“按位置去找”，和具体是什么词无关。上一讲拿掉位置嵌入后复读失败，原因就在这里：没有位置，这个头就不知道“回头 3 格”是哪一格。

## 用代码复现

下面的代码完整地算了一遍 TinyLM 的自注意力；然后用随机向量看看为什么要除以 √*d*<sub>k</sub>；最后估算 Llama-3-8B 一层注意力在长序列下的计算量和注意力矩阵的大小。

```python
import json
import numpy as np

t = json.load(open("tinylm.json", encoding="utf-8"))
X = np.array(t["examples"]["03"]["X"])            # “我 爱 学 AI”的嵌入，4×4
L0 = t["weights"]["layers"][0]
Wq, Wk, Wv = (np.array(L0[k]) for k in ["W_q", "W_k", "W_v"])

def softmax(S):
    e = np.exp(S - S.max(axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)

# 1. 三次矩阵乘法得到 Q、K、V
Q, K, V = X @ Wq, X @ Wk, X @ Wv
print("“我”的 q：", Q[0].round(2), " “我”的 k：", K[0].round(2))

# 2. 打分、缩放、softmax、加权求和
d_k = Q.shape[1]
S = Q @ K.T                                       # 4×4：第 i 行第 j 列 = q_i · k_j
A = softmax(S / np.sqrt(d_k))                     # 每行加起来是 1
O = A @ V                                         # 每个词的输出 = V 各行按权重相加
print("“我”的打分：", S[0].round(4), " 除以 √4：", (S[0] / 2).round(4))
print("注意力权重 A：")
print(A.round(3))
print("“我”的输出：", O[0].round(3), " 每行和：", A.sum(axis=1).round(6))

# 3. 为什么要除以 √d_k：随机向量的点积，标准差随维度变大
rng = np.random.default_rng(0)
for d in [4, 64, 128]:
    q, k = rng.standard_normal((10000, d)), rng.standard_normal((10000, d))
    dots = (q * k).sum(axis=1)
    s = rng.standard_normal((1000, 8, d)) @ rng.standard_normal((d, 1))    # 一个 q 对 8 个 k 的打分
    top = softmax(s[..., 0]).max(axis=1).mean()
    top_scaled = softmax(s[..., 0] / np.sqrt(d)).max(axis=1).mean()
    print(f"d = {d:3d}：点积的标准差 {dots.std():5.2f}（√d = {np.sqrt(d):5.2f}）  8 个里最大权重：不缩放 {top:.2f}，缩放后 {top_scaled:.2f}")

# 4. Llama-3-8B 一层注意力，序列长 8192：投影和打分各要多少计算，注意力矩阵多大
s, d, n_h = 8192, 4096, 32
proj = 2 * s * d * (d + 1024 + 1024 + d)          # q、o 是 4096×4096，k、v 是 4096×1024（第 39 讲）
attn = 2 * (2 * s * s * d)                        # QKᵀ 和 A·V
print(f"投影 {proj / 1e12:.2f} TFLOPs，打分+加权 {attn / 1e12:.2f} TFLOPs；注意力矩阵 {n_h} 个头 × {s}² × 2 字节 = {n_h * s * s * 2 / 2**30:.0f} GiB")
```

“我”的打分： [ 0.0986  0.142  -0.0606 -0.1876]  除以 √4： [ 0.0493  0.071  -0.0303 -0.0938]

## 到了大模型里

**计算量：随序列长度平方增长。**打分矩阵是 s × s 的：每个词都要和每个词比一次。Llama-3-8B 的一层注意力，处理 s = 8192 个 token 时，算 *Q*、*K*、*V* 和输出投影的四个矩阵乘法约要 0.69 TFLOPs，而打分（*QK*<sup>T</sup>）加加权求和（*AV*）要 1.10 TFLOPs，已经超过了投影。前者和 s 成正比，后者和 s<sup>2</sup> 成正比：序列再长一倍，投影翻倍，注意力翻四倍。这就是长上下文昂贵的根本原因。

**显存：注意力矩阵很大。**同样在 s = 8192 时，一层 32 个头的注意力矩阵，每个都是 8192 × 8192，用 BF16 存要 4 GiB，而它只是一个中间结果。第 75 讲的 FlashAttention 用分块计算的办法，根本不把这个矩阵完整地存下来，既省显存，又因为少了大量读写而更快。

**推理时的 K 和 V。**生成新 token 时，新 token 的 q 要和前面所有 token 的 k 打分，再用它们的 v 加权。前面那些 token 的 k、v 是不变的（下一讲会说明为什么），所以可以存起来反复用。这就是第 24 讲预告过的 KV Cache 里存的东西：每一层、每个 token 的 k 和 v。

## 容易混淆的地方

1. **“注意”不是“选一个”。**注意力的输出是所有 v 的加权平均，每个词都有贡献，只是多少不同。即使权重集中在某一个词上，也是“几乎全部来自它”，而不是挑出它。
2. **Q、K、V 来自同一个 X。**“自”注意力的“自”，就是指查询、键、值都来自同一句话。还有一种“交叉注意力”，查询来自一个序列、键和值来自另一个序列（比如翻译模型里，译文去看原文），大语言模型里基本只用自注意力。
3. **注意力本身没有可学的“看哪里”的规则。**学的只是 *W*<sub>q</sub>、*W*<sub>k</sub>、*W*<sub>v</sub> 三个矩阵。看哪里，是 q 和 k 的点积在运行时临时算出来的，所以同一个模型面对不同的句子，注意力图案也不同。

## 回顾

自注意力让每个词根据上下文更新自己。每个词用三个矩阵算出查询 q、键 k、值 v；用自己的 q 和所有词的 k 做点积打分，除以 √*d*<sub>k</sub> 防止 softmax 饱和，softmax 成权重，再用权重把所有词的 v 加起来，就是它的输出。写成矩阵就是 softmax(*QK*<sup>T</sup>/√*d*<sub>k</sub>)·*V*。TinyLM 没训练过，注意力几乎平均分配；训练过的复读模型则学会了“回头看 3 格”。注意力的计算量和显存都随序列长度平方增长，这是长上下文的主要成本。

复读模型有一个我们一直没解释的细节：它的每个词只看自己和前面的词，注意力矩阵的右上角是空的。为什么要这样？如果不遮住，会发生什么？下一讲：**因果掩码**。
